# 资料阅读工作台局部规则

先读[项目AGENTS](../../../AGENTS.md)、[核心开发基准](../../../docs/核心功能与开发基准.md)和[当前状态](../../../docs/当前开发状态.md)。本页只补充reader局部实现约束，旧FE-V阶段门槛已归档，不覆盖当前任务。

- 资料居中、助手按需打开；复用ReaderLab唯一页码、选区、批注和阅读状态，不再存副本。应用级助手容器归外层应用壳。
- 工具紧凑分组，低频参数随模式出现；连续缩放、fit宽度／整页、专注和全屏连接真实状态，退出恢复。不改变批注原始坐标。
- 复用../boardui真实源码、cx与语义token，记录来源／许可；新增组件维护源码扫描。不全项目init或引入preflight。PDF原文颜色／字体不重排，坐标仅用../coordinates，不用CSS补偿覆盖层偏移。
- 保持reader schema兼容；未知记录保留原数据。课程模式校验course/source/hash/preview与服务端revision，保存回执后才显示已保存；冲突先保护／导出再显式重新载入，不静默覆盖。实验快照不自动迁移到课程。
- 普通批注不改变AI附件；取材预览确认后才附带，取消不清空问题／旧附件。输入与中文组合优先，滚动／翻页／中键平移不得抢占编辑，失焦结束拖动。颜色区分新建默认与选中修改；已存变更走历史与保存。
- 无课程的reader-lab／workbench实验入口：固定回复必须标示例，不调用真实模型、不写正式学习事件／成绩／帮助。正式课程统一助手由src/assistant持有并按当前授权运行，实验限制不能解释成全产品禁止联网或真实生成。
- 改动后验证受影响reader／workbench路径和数据保护；仅在实际相关时执行桌面尺寸／键盘／缩放检查，不重新打开全部历史验收。原生125%不能用DPR／CSS zoom冒充。调试故障仅dev=1，正常路径错误、草稿和恢复入口必须可达。
