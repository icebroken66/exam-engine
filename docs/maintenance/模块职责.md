# 实际模块职责与检查映射

更新：2026-11-10；反映 PR-01～04 已落地结构。状态只看 [本地计划](../development/开发拆分与PR计划.md)。

## 调用方向

    main.create_app → learning_routes → learning_sessions / learning_grading / learning_reads / tutoring / learning_evidence
    learning_sessions → course_context / learning_questions / learning_reads / learning_evidence
    learning_questions → course_context / session_access
    learning_grading → learning_reads / session_access / learning（纯规则）
    learning_reads / learning_evidence → course_context
    tutoring → session_access / retrieval；仅用 learning_sessions 的公开 read_learning_session
    course_context → models / source_lifecycle / retrieval / model_gateway
    session_access → models
    learning_routes / main → dependencies → database.get_db / ModelGateway.from_env

main 保留生命周期、恢复、CORS、文件根目录和非学习路由。learning_routes 负责 HTTP 校验 / 异常转换，不复制业务；dependencies 同对象重新导出 get_db，main 保留原网关依赖导出供 override。领域不反向导入 main / router，不跨模块导入下划线辅助函数。learning_sessions 有意公开重导出兼容 worker / 旧脚本。

course_context 负责范围 / 候选 / 签名，learning_questions 负责原题优先 / 生成验收 / 单任务发布，learning_reads 负责公开响应，learning_grading 负责正式评分 / 纠错重算，learning_evidence 保持只读跨轮次投影。事务提交位置、来源 / 版本后校验、帮助独立性、人工纠错优先权与原始历史保持。

前端 LearningPanel 拥有唯一会话状态、草稿和恢复，编排 CurrentLearningQuestion、LearningAnswerForm、LearningAnswerFeedback、TutoringPanel。clients/learning、tutoring、evidence 使用 clients/transport，api.ts 兼容旧路径。公共题型 / 引用 type-only import 无运行时循环。不要再用 api/ 源码目录，浏览器 **/api/** fixture 会拦截模块。
