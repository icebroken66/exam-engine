# 核心功能、关键闭环与开发基准

版本：1.0｜生效日期：2026-11-24（北京时间）｜性质：长期产品与实现约束，不是全部功能已完成的声明。

本文件整合原始产品原则、11月22日至24日资料学习工作区讨论、非线性学习与多模态架构认可、教学闭环讨论及当前代码事实。它替代历史任务书、复核意见和旧排期作为日常开发依据。用户最新明确决定优先；历史建议没有因为被收录而自动变为已批准方案。

当前实现与唯一活动批次维护在[当前开发状态](当前开发状态.md)，代理执行规则见[根目录 AGENTS.md](../AGENTS.md)，原始依据见[归档索引](archive/20261124/README.md)。不要再创建第二套总计划。

## 1. 产品目标与不可丢失的方向

这是以真实课程资料为锚点、减少学生整理与恢复负担的本地学习与复习 Agent。资料既用于生成题目，也能直接阅读、思考和批注。题库、统计和工具服务学习，不以功能数量或 Agent 数量衡量产品价值。

电脑网页优先，手机网页保留为后续目标；原生 App 未决定。当前本地单用户，同伴各自在自己的电脑运行，不以账号平台、公开部署或商业化作为当前开发前提。

用户可以只看资料、独立问概念、直接要求完整讲解、在纸上做题、查资料后回题、暂停或开始另一个事项。关键闭环用于说明能力及验证结果，不强迫用户顺序完成全部步骤。长期方向包括真实课件、跨资料解释、中央内容关联、纸笔与图表、可回访的学习产物，以及统一导师和按需专家。

### 已确认与待定的区别

| 类型 | 内容 |
|---|---|
| 已明确的产品方向 | 资料作为主体、原件只读、独立批注、统一助手、主动取材、有来源解释与定位、非线性学习、多事项恢复、纸笔／多模态、题目与知识关联 |
| 已认可的架构方向 | 统一导师面向用户，Harness维护事实与权限，专家按需参与；不是每条消息启动全队 |
| 有约束的后续目标 | 课程内检索、外部查证、解释保存与双向链接、PPTX直接预览、手机网页；后置不表示取消 |
| 尚需在相关批次决定 | 中央讲解最终布局、精确锚点技术、无起点时保存位置、图片数量及预算、专家路由、框架、自动保存偏好 |

不得将代理的布局提案、接口草案或本文件推荐顺序说成用户已逐项批准。常规可逆实现可依授权自行决策；只对实质产品取舍或缺失授权询问，不要求用户重复确认既有方向。

## 2. 核心能力地图

编号用于需求追踪，不是新任务编号，也不是必须一起完成的验收清单。

| 编号 | 核心能力 | 用户可获得的结果 | 实现边界 |
|---|---|---|---|
| C01 | 课程资料接收与理解 | 批量交课件、往年卷、作业、笔记，知道哪些可用及缺什么 | 保留原件、独立状态、去重与归属；有至少一份有效课程锚点才能进入课程诊断；明确概念问答不强迫先选题 |
| C02 | 资料阅读与个人批注 | 在应用内直接复习，涂写、高亮、移动贴条、恢复位置 | 原件不变；PDF先行；PPTX解析不等于保真预览；整笔擦除不冒充局部擦除 |
| C03 | 统一学习助手 | 围绕概念、资料、题目、作答和反馈自然提问 | 一个前台入口；少管理按钮；普通标记不等于AI附件；草稿不等于提交 |
| C04 | 课程证据查找与解释 | 从授权资料内找到依据，按实际卡点解释 | 区分检索候选与实际补读证据；找不到、冲突、不支持要说明，不编造 |
| C05 | 关联讲解与定位往返 | 解释可联系中央资料／题目，核对依据后回原位置 | 讲解、引用目标和起点分离；无精确证据就页级／任务级回退；不抢焦点、不覆盖作答 |
| C06 | 保存理解与双向关系 | 一次明确保存后，从资料或题目重新找到解释和依据 | 临时回答不自动写笔记；幂等、撤销、版本、失效、反向关系由同一记录派生 |
| C07 | 纸笔与多模态学习 | 题图、手写作答、图表和公式可被实际读取，模糊处可修正 | 实际传图；角色／所属题／版本明确；看不清关键符号不猜测评分 |
| C08 | 非线性上下文与恢复 | 查资料、换题、切课程或中断后仍能找到原任务 | 视图、事项、主题、附件、请求和正式状态分离；新题不继承旧题私有解法 |
| C09 | 证据驱动的教学与独立检查 | 从真实作答定位缺口，获得合适帮助，再独立验证 | 卡点是假设且可纠正；聊天不改分；帮助后正确不等于独立掌握 |
| C10 | Harness与按需专家 | 复杂判读／取证／核查有帮助，普通问题保持轻量 | 权限、版本、预算、恢复由代码控制；专家无额外全局写权限，不为框架而重写 |
| C11 | 外部来源核验 | 需要补充知识时能查看真实取得且支持说法的来源 | 保存URL、标题、片段、获取时间与适用性；模型记忆不是可追溯来源 |
| C12 | 覆盖、章节与时间规划 | 知道未诊断和薄弱处，在有限时间选择下一步 | 先单知识点闭环，再章节和时间；抽样、top-k与有题引用不代表整课理解 |

## 3. 必须连起来的关键闭环

### L1：资料学习与可回访理解

打开资料 → 遇到卡点 → 助手主动取材或在明确课程范围查找 → 有依据解释 → 查看关联讲解／定位证据 → 返回原学习位置 → 按需要保存解释或关系 → 重开仍能回访。

用户可以在任意一步停止。一次提问无须强制保存。核心成功是用户能理解并回到学习，不是消息显示published。

最小交付应覆盖：一份起点资料、一份相关资料、一条解释、一条有效往返关系、一次明确保存与重开；重复保存不重复，目标失效不跳到同名新文件。跨资料查找未接入时可先验证显式附件，但必须标明缺口。

### L2：题目、资料与纸笔之间的中断恢复

打开一道题并保留草稿／纸笔进度 → 查课件或独立问概念 → 必要时附带作答照片 → 获得帮助并核对依据 → 返回原题 → 用户显式作答／提交。

导航不自动提交、判错、完成或开启新题；未上传纸笔内容不可观测。生成中换题时旧结果归旧主题，不能覆盖新题或强制跳回。题目失效或已推进时只能展示合法历史，不把旧题重新伪装成当前可提交题。

### L3：诊断、帮助与独立检查

有效课程资料与范围 → 原题优先诊断 → 正式作答与判分 → 可修正的卡点假设 → 一次帮助 → 根据回应换法／退出／继续 → 显式进入未见题或实质变式独立重测 → 更新有效证据与下一步。

这是产品能力，不是用户被迫经历的固定课表。直接完整求解、暂停和独立探索合法。一次重测仅证明该题表现，延迟保持和整课覆盖需另外的证据。

### L4：请求、故障与可信恢复

接受请求并冻结输入 → 校验权限、来源与帮助规则 → 按需读证据／图像 → 生成 → 发布前复核 → 保存结果与用量 → 展示实际回执。

超时／丢回执先查原request；来源变化阻止过期动作；保存冲突保留本地内容；未知执行不假报失败未收费或自动重发。查看已生成内容、展开、定位、普通批注不生成新模型请求。

## 4. 阅读、取材、回答与学习产物

### 4.1 阅读体验

左侧课程／文件树、中央学习内容、按需打开的统一助手。课程总览、文件阅读、题目、阅读位置与展开状态必须连接真实状态。默认资料入口保留，不能恢复题目独占中央的旧布局。

PDF原排版不被产品主题重排。缩放、适合宽度／整页、专注／全屏、翻页、滚动、输入法与焦点应自然工作。批注使用原始归一化页面坐标，不能靠CSS偏移掩盖坐标错误。笔刷、高亮、贴条属于独立层；撤销与重做、擦除和保存兼容既有数据。

PPTX自动转换需保留原件→预览版本映射，并核对中文、字体、公式和图表；失败有回退。当前人工转PDF限制必须如实说明。

### 4.2 主动取材

助手内“添加内容／从工作区选择”进入临时取材；预览后确认附带。取消／Esc恢复原工具，不创建个人批注、不清空问题或旧附件。普通高亮、翻页、打开助手不自动给AI读页、草稿或全部笔记。

可明确附带：资料选文／区域、公开题干、当前选择与未提交草稿、已提交作答、已公开反馈、用户文字及未来图片。角色可见且可移除／替换；发送后冻结版本，不随页面变化更新历史。

没有附件但问题自足时直接答；只有对象歧义影响解释、读取、写入或独立性才澄清。正文已有完整题干不能因“这题”关键词误拦。补充问题应自然接回原问题，不要求用户先管理技术请求状态。

### 4.3 解释、来源与中央呈现

回应实际卡点：提示、局部步骤、换讲法或完整解释，不机械苏格拉底反问、不强制固定模板。要求完整讲解时应在合理预算内完整回应；不能把强迫多次点击继续作为默认长度方案。

区分资料直接事实、用户提供文字、模型解释／推导、实际外部检索证据。有效ID和匹配引文仅证明身份与文本存在，不能代替语义支持与知识正确性。

中央讲解是临时学习内容，不能改原题、正式答案、原件或个人笔记。正式布局仍需有界实现决定；M2样板不算已接入。来源按钮默认用户点击，用户明确要求“查找并打开”时才执行校验后的跳转。保留起点与证据目标，缺少文字／区域精度时明确回退。

### 4.4 保存与关系

一次明确“保存到此处／建立关联”可保存解释及关系；不得每题强迫记录。自动保存AI笔记策略未定，不得擅自开启。没有有效起点时允许选择落点或存到列表，不凭空往当前页贴条。

最小实现契约：解释身份与内容版本、对应request/topic、起点anchor、目标anchor、概念标签、证据引用、保存命令及revision。具体字段随实施批次定稿，不要求现在新建全套表。

双向链接存一条权威关系，反向展示由它派生；相同命令同载荷重放返回已有结果，不同载荷冲突。允许撤销；删除关系与删除笔记／对话分开。移除来源或版本变化标失效，不按文件名替换。保存、查看、建立关系不增加掌握证据；选题依据关系与用户保存关系分开。

## 5. 状态、身份、上下文与执行契约

### 5.1 状态分离

| 对象 | 责任 | 不能推导的事实 |
|---|---|---|
| 学习事项 | 平台题、外部题、概念探索；可多个未完成 | 被打开不代表已开始／完成／正式当前题 |
| 正式业务投影 | 当前task、阶段、can_submit、帮助与进度版本 | 不能由助手事项状态覆盖 |
| 当前视图／返回书签 | 课程、文件、题目、页、滚动与有效草稿引用 | 不代表注意力、理解或讨论目标 |
| 讨论主题 | 独立／单事项／明确比较的对话范围 | 不必跟随中央当前页 |
| 附件与角色绑定 | 资料、题图、作答、参考、版本与精度 | 不等于正确答案或正式提交 |
| 请求与上下文包 | 当轮冻结输入、纳入／排除、执行和用量 | 不等于当前可编辑草稿 |
| 学习证据 | 正式作答、帮助、判分、复核及有效性 | 聊过／保存过／读过不等于掌握 |

这是职责拆分，不要求一对象一张表。复用现有模型和服务，不造第二套评分、reader状态或万能共享状态。

### 5.2 身份与版本

source ID负责归属，hash负责内容，preview_version负责预览映射；同名不可替代，同hash也不能跨课程任意绑定。资料锚点包含课程、source、hash、预览版本、页及有证据的精度；题目锚点包含session/task及内容版本，不能混填资料字段。

revision用于并发写，内容指纹用于语义有效性；时间戳不是意图或内容版本。请求、保存、帮助与正式提交各有权威命令身份。模型与客户端自报valid不生效，服务端重新检查。

### 5.3 上下文构建

冻结包包括：当前问题、明确目标／比较分组、允许附件与版本、必要有效历史、用户纠正原话、已读证据、所需规则、预算和追踪。记录纳入与排除原因，不记录隐式思维链。

新题默认排除旧题照片、答案和局部解法；显式比较按题分组。课程默认隔离。概念知识可在明确关系和可核查来源下复用；不能简单删历史，也不能把全课历史塞给所有专家。

当前最近六组有效问答限制只是一项实现边界，不是长期记忆方案。裁剪必须提示实际影响；用户否定的旧前提不可因摘要再次变真。未来相关历史恢复／有来源摘要保留原话与纠正链，摘要不扩读取权限。

### 5.4 Harness与工具

模型负责理解、教学、抽取、提出取证和动作候选；代码负责权限、来源、版本、状态、帮助、评分、写入、预算、幂等和发布。

工具依次按需要开放：读公开任务快照、读确认附件、课程检索与补读、图像判读、证据核查、类型化定位／返回、明确保存、合法暂停／恢复、题内帮助适配、实际外部检索。不提供任意本机路径读取、DOM操纵、自动提交或聊天直接改分能力。

请求恢复按已接受／取证／待复核／已发布等实际持久状态处理，具体状态名沿现有契约。上游未知是否执行时先查询与保留账本；request去重不能被宣传成所有供应商绝对只执行一次。取消前端等待不等于取消模型计费。

## 6. 多模态与按需专家的实现约束

照片保留原图、hash、所属课程／事项、角色、顺序、旋转／裁剪映射、转录与确认版本。新照片明确是补充、替换还是比较；旧请求仍读冻结旧版本。已说明“本题作答”不重复问角色；确有歧义才确认。

必须向视觉模型发送实际图像或可核验裁剪；坐标、文件名、OCR文本不能冒充看懂图表。负号、上下标等关键符号不清时标疑点、请确认或补拍；明确部分可以继续说明。识别正确与推导正确分别验证。图片上传不自动正式提交或产生attempt。

统一导师直接处理简单问题；复杂图像判读、多资料研究、争议推导／判分核查可按需调用工具或专家。委派包含request、课程／事项／主题、冻结版本、授权材料、问题、输出契约及共享预算。依赖识别结果的检索应顺序，独立取证才并行。

专家不自行扩权限、改目标、写成绩或发布前台答案。导师整合、Harness校验。工具够用时不升级Agent；是否采用LangGraph等框架以具体收益决定。专家质量、延迟、成本和失败传播需同条件对照，不预设多Agent更优。

## 7. 教学、正式作答与学习证据

### 7.1 资料与题目质量

批量输入保留清单、课程／学期／角色、每份文件状态及失败原因；局部失败不撤销成功文件。排队、未分析、缺失区分。受限平台由用户自行登录下载回传，不收集密码或绕过访问限制。

原题优先，其次可追溯实质改编、课件／作业改编、有证据原创。保留题号、子题、选项、分值／年份未知、原卷页、证据与答案来源。AI解答不能标成原卷答案。条件、公式、图表缺失则不发布可靠题目；生成与验题分开。

教师当期明确要求决定考试范围，课程资料决定本地符号与深度；往年卷不保证必考。资料与参考答案冲突显示差异，不静默覆盖。抽样检索不能宣布整课覆盖。

### 7.2 卡点观察与帮助

观察来自真实消息／attempt，保留学生原话、可能卡点、支持／反证和未知。省略条件不直接判成概念不会；用户纠正后修订关联，不能贴永久能力标签。

无从开始给可执行小步；部分正确保留正确部分；同一种解释无效则换表示／反例／粒度；要求完整解法可以完整讲；连续无进展提供补先修、换路径、暂停或退出。不给无效解释套无限循环，也不按固定轮数机械撤帮助。

### 7.3 评分、重测与纠错

正式点击提交才形成作答与评分，优先确定性或已验证等价规则；开放题按评分要点，不确定则待复核。普通聊天／检索／视觉工具不得读取隐藏教师答案；专用教学适配服务按权限与帮助同意使用，不把全部教师字段交给通用导师。

独立重测相关解释实际提供前检查同意与帮助记账；纯导航、暂存图片、界面问题不一律记帮助。不能用无关联文本／纸稿入口绕过，也不能让模型标签代替服务端判断。

保留原答、原判分、人工纠正、新结果和理由。人工更正不被AI覆盖；重复提交／重判不增加独立证据。坏题、来源移除或题目变更需使相关证据待复核并可重算；不能用新条件套旧作答。

新题检查复用正式选题、发布、作答、判分和帮助生命周期，不另造临时答题器。重测应不同原题或实质变式；即时模仿正确不等于掌握。跨轮次证据只能参考，不复制掌握分数或跳过诊断。

## 9. 默认推进主线与有界交付

截至本版，优先补L1／L2中尚缺的连接，再深化L3；这是开发建议，不表示本轮已启动这些功能。

1. 正式解释与中央学习位置关联，明确返回与一次保存，形成可重开的产物。
2. 在一门课两份PDF内查找相关概念、补读、定位往返；复用现有检索。
3. 用真实课程走通阅读→求助→查证→返回→保存→回题，直接阻塞才修复。
4. 接入一道外部／平台题和一张纸稿的真实视觉路径，支持关键符号纠正与版本。
5. 结合实际学习路径接可修正卡点、帮助调整与独立新题检查；外部查证、PPTX、专家、手机、章节／时间按真实缺口继续。

第1项可拆成“临时关联呈现”和“保存关系”两个批次，不能为一次交付强塞全图。若真实失败证明必须先检索或先视觉，可在当前状态写明证据和依赖后调整。旧PR-08、章节、时间规划不因旧编号自动优先；也不能取消原教学目标。

每批只有一个用户问题、一个可观察成果、3～5个事先冻结的验收点和明确范围。批次结束必须交付可运行能力或可直接支持实施的必要决定，不能反复把“再写一份任务书”作为进度。
