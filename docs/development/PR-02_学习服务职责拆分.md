## 范围与依赖

| 模块 | 负责 | 依赖规则 |
|---|---|---|
| course_context | 语义主题、范围采样与准备、有效题目候选、整课签名 | 依赖模型 / 网关 / 来源，不依赖会话编排 |
| learning_questions | 原题优先、跨轮次去重、生成与独立验题、发布单个任务 | 使用 course_context 与 session_access，不自行提交事务 |
| learning_reads | 作答 / 当前题 / 会话 / 历史响应投影与已诊断主题 | 使用 course_context 与 session_access，无网关调用 |
| learning_grading | 正式提交、判分、复核、人工纠正及有效状态重算 | 使用 learning_reads 与 session_access，不反向依赖编排器 |
| learning_sessions | 首次 / 后续规划、恢复、阶段推进与提示操作 | 调用领域公共入口，保留原公开 API 的明确重新导出 |
| learning_evidence | 只读跨轮次证据与复习依据 | 直接使用 course_context.course_signature，移除延迟导入编排私有函数 |

read 模块是必要的响应投影依赖：判分要返回会话状态，而该响应包含候选 / 主题统计。独立提取它避免判分反向导入编排器，未使用回调注入、共享可变服务或万能工具模块。learning.py 的纯判分规则不需要修改。

八个跨模块能力公开命名，更新仓库调用方；模块内部辅助函数保留私有。测试直接导入领域归属，原题去重测试的 monkeypatch 移到 learning_questions._new_original_task，保证仍截获实际调用，未增加失效的兼容私有别名。main、worker、tutoring、现有回放工具通过原有公开入口继续工作。

改动文件：以上六个领域 / 编排模块、四个原测试文件、新增边界测试；两个现有评估脚本只补充迁移后实现文件的报告指纹，不改变模型调用或运行保护。具体文件指纹见末节。HTTP、前端、models、schemas、数据库和正式资料不改；PR-03～05 不包含在本卡。
