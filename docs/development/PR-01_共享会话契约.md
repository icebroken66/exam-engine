## 契约与兼容

| 公共接口 | 保留的职责 |
|---|---|
| get_learning_session / get_current_task | 原有读取、所属轮次检查与 404 / 409 |
| get_latest_attempt | 按 attempt_number 取最新作答 |
| get_progress_version / assert_session_progress | 原版本输入、刷新与模型返回后的进度保护 |
| assert_no_running_tutoring | 正在生成时阻止正式作答 / 推进 |
| record_session_event | 仅加入调用方事务，不自行 flush / commit / rollback |
| read_evidence_citations | 原引用顺序、摘录长度及来源移除标记 |
| LearningSessionError | 原 status_code / message 与同一异常类型 |

HTTP、公开字段、数据库和网关接口没有变化；所有事务提交 / 回滚与模型调用位置保持。tutoring 仅从 learning_sessions 使用公开 read_learning_session，不把包含范围和选题规则的响应组装强塞入共享访问层。main 原有 LearningSessionError 导入通过 learning_sessions 重新导出保持类型身份；全仓搜索未发现依赖被移动私有名的其他调用方或测试注入路径，无额外私有别名。
