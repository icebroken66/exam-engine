# 学习Agent需求覆盖检查与效果验证方案

日期：2026-11-23。状态：设计检查与验证方案，不是效果结论。用户询问如何验证以及现设计是否足以满足需求；本轮只检查与记录，不开始付费实验或业务实现。

依据：[状态与上下文契约](学习Agent_状态与上下文契约草案.md)、[场景表](学习Agent_非线性场景决策表.md)、[既有带学回放](../../../../evals/tutoring/README.md)及[真人试用包](../../../../evals/tutoring/trial-protocol.md)。复用原证据，不再建立另一套互相竞争的评分历史。

## 1. 结论与责任

目前方案可作为有限原型的架构基础，尚无证据证明满足所有最终要求。设计已覆盖关键职责，不等于能力已经实现、易用或有教学收益。用户负责学习需求和实际卡点表达；开发设计方负责识别冲突、减少操作负担、定义验证、如实报告失败，不将方案风险转嫁给用户的设计水平。

## 2. 覆盖与风险

| 用户要求 | 当前基础 | 缺口／必须验证 |
|---|---|---|
| 阅读课件并批注 | 电脑PDF阅读、三类批注与服务端保存已有局部工程证据 | PPTX仍需人工导出；字体保真、长材料／边界格式不能全面承诺 |
| 一个简单统一助手 | 单入口纠偏已做，FE-V09已写 | 自动草稿与低负担交互仍需实施／用户评审，不能靠折叠所有技术控件解决 |

## 3. 验证策略：先做可证伪的小范围，而非一次实现全图

### 阶段A：冻结要求与小型评测包

把上述要求写成可观察结果，分别标工程确定性、模型质量和用户价值。不以一个总分抵消严重失败。复用既有课程资料和带学夹具，先选一门课两个相关考点，准备约12～20个开发案例，作为工作量建议而非统计充分性；另封存未参与调试的内容／措辞。

案例同时含清晰与模糊纸稿、图表／公式、部分正确与错误推导、直接求解／只要提示、用户纠正、切题后旧回复、查资料中断恢复及不应调用专家的简单问题。逐项保存可核查答案／允许行为／禁止行为、适用条件与来源。开放问题允许多种合理解法，不以精确匹配某句回复判优劣。

### 阶段B：最小真实回答对照

先接一条有限真实能力：确认内容／纸稿→有效证据→解释→引用定位；完整请求恢复和教学权限在启用前完成。与同模型、可比输入证据和预算的直接导师基线比较。单导师＋工具作为可运行基线，再只对复杂子集加入按需专家；这不否定多Agent目标，而是测清其收益。

逐条看实际manifest、图像衍生物、检索证据、工具调用、输出和费用；不只看最后文字。相同证据的策略比较与各自端到端检索能力比较分开记录。短问题不必强制委派，专家失败不能伪装成完成核查。

### 阶段C：失败归因与回归

每次失败分类为媒体／识别、上下文归属、检索／证据、教学回应、动作／定位、恢复／并发、UI负担。保存原输入、冻结版本、预期与实际，优先最小根因修复；复测原案并跑相关回归。新鲜样本一旦用于调试即转开发／回归集，不再称未见。关键随机失败多次重复，报告逐次结果，不以最好一次代表稳定性。

### 阶段D：真实用户短试用

沿既有试用包开展本人及少量参与者试用，记录独立操作卡点、观察者介入、理解过程与未见题原答。1～2人仅发现具体问题，不输出普遍学习提升；条件允许再做延迟检查。用户明确表达不满意即保存失败，不用工程通过覆盖产品反馈。邀请及外部沟通需另有授权。

## 4. 验收门槛与证据

- 硬阻塞：跨课／跨题私有内容污染、隐藏答案泄露、虚构来源、原件／笔记丢失、假报保存或模型已回答、绕过重测帮助同意、模糊关键符号仍确定评分。出现后先修复，不能用综合平均分冲抵。
- 模型维度分别看：关键符号识别与适当澄清、问题归属、证据支持／引用可达、解释是否回应卡点、用户纠正后是否调整、是否越界附送答案。人工按明确rubric评审，模型评审只辅助筛查；开发者不确定的知识先核查，不让用户承担全部校验。
- 成本与体验分别记录调用数、图像／token、实际费用或价格未配置、延迟分布、重试和无效操作；还应记录用户纠正系统／手动整理上下文的次数。阈值按样本和预算在真实验收任务中预先设定，不事后为通过调低。
- 状态测试用Mock／临时库；手写识别、真实引用与教学质量须真实模型和原件证据。真实调用需单独确定模型、次数／token或金额上限、停止条件与素材范围，本方案不构成授权。
- 每次报告明确：当前验证范围、失败／退化、未运行、当前能给用户什么、仍不能承诺什么。

## 5. 当下建议与范围控制

保留FE-V09交互收敛目标，避免继续堆面板。与此同时先做评测材料／验收rubric设计，不等待所有Agent实现；状态／请求底座和教师权限先于真实教学发送。随后用有限课程的真实回答暴露问题，再决定专家路由及关联产物的投入。

目前不应继续扩大全课程规划、多个常驻Agent、联网和自动PPTX转换。不是取消长期需求，而是先检验最不确定的“看懂输入、解释有依据、切换不串题、用户觉得有帮助”。本轮方案不自动产生新实施卡或修改现有阶段验收状态。
