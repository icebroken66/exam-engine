# FE-V07：树形导航、课程总览与批注擦除任务书

日期：2026-11-23（北京时间）｜版本：1.0｜状态：任务书已编写，开发待开始。

依据：[讨论记录](../原始讨论与设计/2026-11-22_资料学习工作区讨论记录.md)，前置：[FE-V06 任务书](FE-V06_资料入口与跨页面体验整合任务书.md)及[实施报告](../实施验收与复核/FE-V06_实施与验收报告.md)。任务编号、范围与状态统一在[开发计划](开发拆分与PR计划.md)维护。本轮只编写任务书，不代表授权执行代码、完成验收或确认最终视觉。

## 1. 目标与用户问题

用户希望像编程软件的资源管理器一样展开课程与资料：点击课程看总体情况，点击文件直接阅读；左右栏可收展，助手入口明显，中央区域按任务切换。同时，现有批注只能选中整笔删除，缺少直接擦除工具。

本卡围绕以下路径实施增量：课程树 → 课程总览／资料阅读／练习 → 左右面板独立切换 → 笔刷与擦除 → 保存和恢复。复用现有阅读、笔记、助手与评分机制，避免复制状态或重写业务。

## 2. 范围与前置

| 本轮必须完成 | 明确后置 |
|---|---|
| 课程为父项、资料为子项的树形导航 | 编辑／拖拽文件夹、移动资料、课程嵌套、多标签 IDE |
| 点击课程进入总览；点击支持的文件进入中央阅读 | 自动 PPTX 转换、编辑 PPT 原件 |
| 左侧导航与右侧统一助手独立展开／收起 | 手机网页、原生 App、复杂悬浮停靠系统 |
| 课程总览串联继续阅读、练习和题目管理 | 新学习调度、统计口径、自动资料关联题目 |
| 整笔橡皮擦、连续手势撤销与保存恢复 | 局部线段擦除、套索、多选、形状识别 |
| 桌面入口、键盘、版本冲突及现有功能回归 | 真实 AI 发送、联网检索、多用户部署 |

本卡将橡皮擦首版限定为**整笔擦除**：触及笔迹后删除该整笔。用户要求擦除能力，局部／整笔形式此前未定；本任务书选择较小可验收范围，样板需明确告知，不能称已支持局部擦除。

开工核实 FE-V06 最新代码和失败／未决项，保留其待用户评审状态，不自动改成已完成。FE-V07 提供新反馈的增量验收，不重跑全部历史设计讨论。记录实际基线与未提交差异，保护工作区用户文档和前置实现；若发现数据、身份或恢复阻塞先做最小修复并留痕。

## 3. 导航与中央内容契约

### N1：课程树

- 第一层为课程，子层为该课程资料，课程之间不构成父子关系。首版不创建虚拟章节或推断目录；已有真实相对目录可显示为辅助文字，不强制新建多级文件树。
- **课程箭头只展开／收起**，不改变中央内容或助手上下文；**课程名称进入总览**，不同时触发反向折叠。两种目标都需明确的可访问名称和焦点行为。
- **文件名称直接打开资料**。当前 PDF 走真实 course／source 校验；不支持的格式提供清楚说明与下载／原件入口，不进入空白阅读器。阅读能力不因 AI 解析排队一律禁用。
- 当前中央对象与树中选中项同步。展开状态和当前选中状态分开；折叠当前课程不清空中央阅读，课程行保留当前内容归属提示。
- 支持长文件名悬停／焦点查看、同名资料区分、空课程、资料加载中、读取失败和重试。来源被移除后不可当有效文件打开，现有历史／归档访问规则保持。
- 展开节点只按需读取该课程资料，不预读所有课程原件／全部 PDF；缓存按课程隔离，旧请求可取消或忽略，不能将 A 课程的晚响应画到 B 下。展开失败只影响相应节点。
- 大量资料允许内部滚动，真实文件不因只显示前几条而永久不可达；分页／加载更多若采用需显式可用。课程新建、上传和资料管理入口保留。

### N2：课程总览

- 显示实际课程名、必要课程信息，以及继续阅读、继续练习／开始练习、课程资料和题目校准／管理入口；学习记录、考点概览及课程管理保留可发现路径。
- 没有阅读记录时不伪造继续阅读；无活跃练习时显示开始练习，点击仍走原会话规则，查看总览不创建任务或触发付费分析。
- 区分“练习题目”（作答）与“题目校准／管理”（检查题目）；不将二者合并为模糊按钮。资料相关题目自动关联尚未实现，不摆放假入口。
- 继续阅读只用服务端有效快照，继续练习只用实际会话；读取失败显示局部失败，不让总览整体空白，也不显示假零值或虚构掌握率。
- 首版只汇总已有数据；需要新只读接口时写明字段、来源与过滤规则，无记录与失败分开。不得为了填满卡片新增未经定义的学习统计。

### N3：中央工作区与路由

- 中央单一视图承载课程总览、资料阅读、练习及必要管理页；先不做多标签。左右壳层在这些视图间保持一致，不把阅读器当作跳出产品的孤岛。
- 显式点击课程名称进入总览，这覆盖 FE-V06 中课程点击默认资料页的旧规则；明确指定资料／练习／session 的深链不被强制转到总览。旧 URL 保持兼容，必要时映射到新壳层并保留 course／source／session 身份。
- 现有独立阅读 HTML 可保留为兼容／开发入口；正式路径应呈现同一导航壳层和中央阅读。实施前说明如何复用模块与路由，不以复制两套导航／助手或另存一套会话应付整合，也不强制引入某个路由框架。
- 刷新、前进后退、浏览器直接打开资料链接均恢复正确中央对象和树归属；非法身份、删除课程／来源有错误与返回入口，不自动跳到另一门课。
- 阅读位置、笔记与已保存状态沿现有服务端恢复；切换前处理待保存／保存中／失败，不能强制卸载丢掉笔迹。正式作答草稿继续按原范围保留；跨课程切换、返回和刷新分别测试，不承诺尚未实现的服务器草稿同步。
- 文件切换不自动替换助手上下文；仅明确“向助手提问／关联本题”等动作更新关联，旧上下文持续标明原资料／题目。

## 4. 左右面板与视觉要求

- 左侧课程资料栏、右侧应用级助手分别提供明显开关，可独立开合。收起后保留带名称或可识别图标及提示的恢复入口，不把功能藏到不可见边缘。
- 桌面默认采用参与布局的可收缩侧栏，展开不遮挡课件。无需本卡实现浮窗拖拽或多种停靠方式。AI 开关优先使用图标＋“AI 学习助手”文字，按下状态与实际展开状态一致。
- 记住左右栏显示偏好，按浏览器本机 UI 状态保存并版本化，不篡改课程／资料身份。保存偏好失败不阻止使用，也不将偏好开关计为笔记内容修改。
- 1024px 下双栏展开须有明确降宽或自适应收起策略，禁止压成无法操作的中央狭缝。临时收起须可感知、不丢数据，不永久覆盖用户宽屏偏好；进入宽屏后的恢复规则写进设计。
- 面板开合保留阅读页与显式缩放、草稿和批注历史；适应宽度模式允许重新计算，数值缩放不被擅改。课件／批注定位继续满足原最大 4 CSS px 误差。
- 开关焦点可见，关闭后合理回到触发器，不能抢走正在输入的焦点。减少动态效果时仍可操作。内部滚动区域遵循既有滚动渐隐规则，不遮住首行。
- 延续 FE-V06 的共享色彩与 BoardUI 规范；先读实际 Skill 和组件示例，树形控件优先核查已有 Tree View 或可访问组合，不凭组件名称猜接口。新增控件记录来源／许可、依赖与 CSS 范围，禁止全站 init。
- 总览、阅读和练习是同一产品；不再增加竞争性的全局风格。更新 design.md 的既有设计契约，旧方案保留历史标识。

## 5. 整笔橡皮擦要求

### E1：工具与作用对象

- 工具栏新增“整笔橡皮擦”，与笔刷／阅读／选择互斥，有明确选中状态及擦除范围指示。提供有限大小选项，默认命中半径建议 8 CSS px；具体范围在样板中定稿并记录。
- 擦除仅作用于当前文档、当前页、可见个人自由笔迹。高亮、贴条、原课件文字／图形、AI 临时指示均不被擦除；隐藏批注时禁用擦除或明确不命中。
- 左键按住拖动擦除，松开结束；点击也可擦除目标整笔。多条重叠且都在擦除范围内时均可被移除，行为在提示和验收中一致。
- Esc／右键可退出工具回到阅读，沿用已有取消逻辑；不清空助手上下文。中键平移不擦除。Delete／选中删除继续保留，不互相替代。

### E2：几何与手势事务

- 命中依据真实笔迹折线段与擦除轨迹距离，考虑笔宽及显示变换；不能只用整条笔迹的包围盒判断，否则会误删空白区域中的线。快速移动时检测两采样点间路径，不能只测指针离散点。
- 擦除大小按 CSS 显示像素解释，浏览器缩放、阅读缩放和不同页面比例下表现一致；不改存储笔迹坐标来适配擦除。
- 一次按下到松开的连续手势，即使擦除多笔，也形成一次撤销动作；一次撤销恢复该手势全部删除，重做再次删除。擦到空白不新增历史、不触发无意义保存。
- 建议手势中显示临时移除，松开时一次提交批注与保存。Esc、pointercancel、失焦、意外离开或失去捕获时回滚本次未完成手势，保留此前已提交记录；所采用取消规则必须有测试，不允许半笔删除无法撤销或后台继续擦除。
- 翻页、切文档、切工具和面板布局变化不得留下悬挂手势；先结束／取消再切换，不能在新页继续删除。

### E3：保存与兼容

- 复用已有批注列表删除和历史，不引入“白色笔刷覆盖”伪擦除，不修改原 PDF／PPT。整笔擦除原则上不需要更换批注 schema。
- 只在完整手势提交后进入自动保存；服务器回执前不误报已保存。断网／409 时保留当前结果并沿现有重试／导出／显式重载规则处理。
- 已保存后刷新／重新打开，同笔迹仍已删除；未擦除高亮与贴条完整。旧记录可读取，本机与服务端两模式均验证。

## 6. 键盘、数据和工程边界

- 树导航按选定控件的可访问模式实现并文档化：上下移动焦点、左右展开／收起、Enter 进入所指对象，鼠标箭头与名称动作仍分开；折叠包含焦点的节点后焦点回父项。编辑输入时不抢占方向键、删除或中文组合输入。
- 展开偏好、当前中央路由、当前课程、阅读状态与助手上下文各有明确归属；不要将“树上焦点”误当作“当前课程已切换”。
- 快速切换取消／忽略过期请求；列表、总览摘要和助手各按 course 身份隔离。读取／展开操作不创建学习会话、解析任务或调用模型。
- 复用现有摘要接口、课程列表和资料数据。若增加只读总览聚合接口，说明真实数据来源、上限／分页、错误、权限与生命周期，无 N 次原件解析，不下载全部快照作列表。
- 阅读器只在需要时加载，默认总览不加载 PDF worker；整合避免同一文档双实例渲染。保留独立实验入口的复现办法，但不在正式导航引导用户误入。
- 不改评分、独立重测同意、帮助记录与正式提交规则；统一助手真实发送仍未启用。只在隔离库／公开夹具验证，不默认操作正式库、付费调用或发布。

## 7. 验收规范

真实 Edge、Chrome；CSS 视口 1024×768、1440×900、1920×1080；浏览器 100%／125%，阅读器至少 50%、100%、200% 和适应宽度。手机网页不在本轮。所有必选项记录通过／失败／未运行、实际步骤和证据位置。

| D17 | 键盘树导航、工具／面板焦点、中文编辑 | 语义与键盘有效，输入优先，面板关闭返回合理焦点 |
| D18 | 新建／上传／归档／移除资料、无效身份 | 原生命周期规则保持，树和中央失效状态解释清楚，不跳到别课 |
| D19 | 原笔刷／高亮／贴条、颜色、历史、统一助手 | 原功能不退化，无新增模型／成绩／帮助副作用 |
| D20 | 构建、回归与实际临时 API 联通 | 受影响测试通过，真实恢复／冲突可复现，默认总览资源无阅读大包泄漏 |
| D21 | 用户完整路径与视觉试用 | 留存实际反馈、改动和未决点；未反馈标待反馈，不造满意度 |

D11～D16 使用多条相交／稀疏／长折线和邻近高亮／贴条，至少三处分布位置及两种笔宽。几何单元测试之外必须有实际浏览器指针操作，不能只调用内部删除函数冒充擦除通过。定位需页面与覆盖层实测，不仅比较同一变换函数输出。

## 8. 推进步骤与交付物

1. 核对前置，提供导航／中央状态图、左右开合规则与整笔擦除说明；用真实内容的可操作样板评审，再收敛样式。橡皮擦可单独在隔离 reader 用例开发，不依赖壳层全部完成。
