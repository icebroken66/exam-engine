# FE-V01：课件阅读与批注小型技术验证任务书

日期：2026-11-22（北京时间）｜版本：1.0｜状态：任务书已编写，开发待开始。

本轮交付任务书，不代表已完成下列实现或验收。任务编号与状态统一登记在[开发计划](开发拆分与PR计划.md)。需求依据为[讨论记录](../原始讨论与设计/2026-11-22_资料学习工作区讨论记录.md)，用户最新明确范围为：**先做电脑网页，不做手机网页。**

## 1. 目标与完成后应作出的判断

验证用户能否在电脑浏览器内按原版面阅读课件，在独立图层上涂写、高亮、放置文字贴条，并可靠选取、定位和恢复内容。验证结果用于确定精细前端设计的技术边界。

必须回答五个问题：

1. 选定格式如何稳定显示中文、公式、图形和表格？PPTX 到只读预览的可行路径是什么？
2. 可选文字与图片／公式区域如何选择，如何形成可供后续 AI 使用的上下文？
3. 笔迹、高亮和贴条能否在缩放、翻页、窗口变化及刷新后保持正确位置？
4. 选区提问入口与引用定位／返回能否在没有真实 AI 的情况下正确工作？
5. 哪些代码可以进入正式阅读器，哪些只是验证夹具；进入精细设计前还有什么阻塞？

“像 WPS 一样查看”在本卡中指保留原版面的只读阅读体验，不包含编辑原 PPT、动画播放或完整办公软件能力。

## 2. 范围与明确边界

| 本轮必须完成 | 本轮不包含，后续另开任务 |
|---|---|
| 一种主预览格式的实际运行阅读器；PDF 为优先评估候选 | 所有资料格式的完整支持承诺 |
| PPTX 预览路径的小样验证与结论 | 批量自动转换、生产级转换服务、动画和视频播放 |
| 页码、缩略图、翻页、缩放、适应宽度 | 全课程首页、全站导航重做、最终视觉定稿 |
| 文本选择和区域框选 | 扫描件自动 OCR、复杂公式语义识别 |
| 自由笔刷、区域高亮、可移动文字贴条 | 富文本编辑器、手写识别、协作编辑 |
| 本机浏览器的自动保存与恢复验证 | 账号、云同步、跨设备恢复、正式笔记后端 |
| 上下文预览、固定引用动作、定位及返回 | 真实 AI、联网检索、知识库建设、题目关联实现 |
| 电脑网页的鼠标和键盘操作 | 手机网页、触屏手势、原生 App、完整暗色主题 |

三种笔记形式均需有可操作实现，不能以按钮占位冒充。本轮范围收窄不删除长期需求，见讨论记录。

## 3. 开发环境、位置与变更边界

- 实际基线在开工时用 Git 核实并记录；编写本任务书时最近代码提交为 `ff7bac3`，当前分支为 `chore/pr-05-maintenance-baseline`。不得把旧 main 默认当成已含维护成果的基线。
- 保留现有未提交文档与用户修改。建议在 exam-engine 中使用独立的验证入口，准确 URL 和启动命令写进交付说明；该入口不得取代正常课程默认入口，也不得随加载触发资料解析、学习会话或模型调用。
- 复用 React／TypeScript／Vite。阅读、锚点、批注数据与演示面板分清职责，避免把全部状态塞回 App.tsx 或 LearningPanel.tsx；不为本卡进行全站重构。
- 不修改正式数据库、上传原件、学习状态、评分、帮助记账或现有模型提示词。测试资料使用独立副本；新建实验接口也只能访问隔离目录，不提供任意本机路径读取。
- 优先按需选择浏览器阅读／绘图依赖，记录准确版本、许可、用途、构建影响和回退方法。PPTX 转换若依赖本机软件，记录版本、字体与安装条件，不静默修改 WPS／Office 环境，不把在线文档预览服务作为默认方案。
- BoardUI 用于验证页所需控件与样式；先检查实际源码和官方用例，再按需安装。主项目接入前说明 Tailwind／全局重置与既有 CSS 的影响，限定作用范围，验证旧页面。禁止直接全项目 init、复制实验项目全部样式覆盖主站，或为采用模板引入另一套聊天后端。
- 如果隔离样式仍不可行，可先用现有基础控件验证核心能力，记录原因及后续迁移点；不能因为组件库接入阻塞阅读定位验证。本轮不以最终视觉成熟度作为通过条件。

## 4. 样本与技术选型验证

### 4.1 最少样本集

| 编号 | 内容 | 目的 |
|---|---|---|
| S1 | 一份允许本地使用的真实课件副本，至少 10 页 | 检查真实排版、缩略图与翻页 |
| S2 | 可入库的自制小夹具：中文、跨行文字、数学公式、图形、宽表格；含横版和竖版／不同页尺寸 | 可复现检查选区、坐标与复杂内容 |
| S3 | 无文字层的图片页或扫描 PDF 页，可合入 S2 | 验证明确回退到区域框选 |
| S4 | 至少一份真实或具有代表性的 PPTX 小样，至少 5 张幻灯片 | 评估转为预览后的版面、页序与文字能力 |
| S5 | 损坏／不支持的文件、同文件名但内容不同的两个版本 | 检查失败与版本隔离 |

样本可重合但覆盖点不能省略。样本清单记录来源类别、页数、大小、SHA-256、是否有文字层及使用权限。私有原件、截屏和摘录留在被忽略的验收目录；入库夹具不得包含私人课件内容。

### 4.2 格式选择规则

- 先对主格式做小样，记录采用和淘汰方案的理由，不展开无边界的阅读器比较。
- PPTX 可以转换为 PDF 等只读预览。若本轮只有人工导出流程，应明确标为人工预处理，记录操作和原 PPTX 至预览页的对应关系，不能宣称已支持上传 PPTX 自动预览。
- 在原查看器与预览中并排核对 S4 全部样本页；S1 至少检查首页、末页及 3 个复杂页面。按中文、公式、图形、表格分别登记缺失、裁切、替换和字体问题。
- 关键公式、文字条件或图形丢失，禁止宣称该样本渲染保真通过。PDF 验证可单独通过；PPTX 不可行时交付明确失败／依赖报告，不把失败隐去。任务整体结论按第 10 节处理。

## 5. 功能要求

### R1：原件只读与阅读

- 打开本地文件／隔离样本，显示文件名、总页数和当前页。电脑侧提供缩略图、上一页／下一页和输入页码跳转；首尾及非法页码处理明确。
- 提供适应宽度和至少 50%、100%、200% 缩放。课件超出阅读区域时允许阅读区域自身滚动，不导致整个应用横向溢出。
- 明确区分空状态、读取中、可阅读和失败；失败显示原因与重新打开入口，不能无限加载或以空白页冒充成功。
- 预览、批注和截图操作不写回原文件。开始与验收结束核对原件 SHA-256 相同。

### R2：选区与上下文

- 文字层可靠的页面支持鼠标选择至少单行、跨行中文，展示所选文本及页码。区域选择和自由笔刷不能抢占文字选择事件。
- 区域框选可覆盖文字、公式和图片，形成可见矩形；支持取消、重选，越界部分被限制在页面内。无文字层时显示区域选择入口，不伪造识别文字。
- 选区可执行“问 AI”“高亮”“添加贴条”。本轮“问 AI”只打开上下文预览和可编辑问题草稿，清楚标明未连接模型，不发真实请求，不生成学习成绩。
- 上下文包含资料版本、页码、文本（存在时）、一个或多个页面区域。图像区域可提供按该范围裁剪的预览或稳定裁剪描述；不得未经标记将整页冒充所选区域。
- 打开上下文面板后，单纯翻页不能偷偷改掉原提问目标；重新选择另一段时明确替换当前上下文，保留问题草稿并更新可见页码／选区。用户可移除上下文。

### R3：三种批注

- **笔刷**：至少一种颜色、可配置的有限笔宽，支持连续自由笔迹，松开指针结束一笔。指针离开区域、窗口失焦或取消时不得留下持续绘制状态；撤销以一笔为单位。
- **高亮**：至少一种半透明区域高亮，不遮住原文；支持多处标记。可选文字创建的高亮保留跨行区域；页面只有图片时允许手动框选。
- **贴条**：在页面位置新增纯文本笔记，可编辑、拖动和删除。拖动手柄与文本编辑分开；贴条不能永久移出可访问范围，窗口缩小时仍能打开编辑。首版不要求自由调尺寸和富文本。
- 三种形式可同页共存。提供明确的阅读／选择／框选／笔刷等当前模式，提供撤销、重做、删除选中批注及隐藏／显示全部个人批注。
- 撤销／重做至少覆盖当前页的一笔、一次高亮、新增／移动／编辑／删除贴条；一次完整拖动或一次编辑提交作为一步，刷新后不要求恢复撤销栈。隐藏不删除，阅读模式不误画。

### R4：坐标、身份与版本

- 批注关联文件内容身份、预览版本和稳定页号／页身份；相同文件名不能作为唯一标识。翻页后不能显示别页笔记。
- 使用页面坐标或归一化坐标保存，统一定义坐标原点、尺寸及变换。屏幕缩放、阅读器缩放和滚动只改变显示映射，不重写原始锚点导致累计偏移。
- 文本锚点保留选中文本和区域，可附上下文；文本提取失败不影响已有区域锚点定位。旋转如不支持应禁用并说明；不得显示无效旋转按钮。
- 同名新版本内容变化时，不自动继承旧批注。旧数据保留，不因尝试新版本而删除。预览重建导致坐标不兼容时提示，不强行套用。

### R5：最小保存与恢复

- 验证版可使用 IndexedDB 等本机浏览器存储，显示“本机验证数据”的范围；同一浏览器重新选择完全相同文件后可恢复批注。不得宣称跨设备或服务器保存成功。
- 批注操作结束后自动保存；连续操作可合并，在停止操作后 1 秒内开始保存。状态必须与实际存储结果一致：待保存／保存中／已保存／保存失败。
- 刷新前已成功保存的三种批注、最后阅读页和 AI 面板开关可恢复。浏览器不能重新读取原文件时，提示重新选择文件，匹配身份后恢复，不展示一个失效的“已打开”状态。
- 写入失败时保留内存中的笔记和问题草稿，显示未保存并提供重试；提供导出验证数据 JSON 的应急入口，不含原课件文件。未保存时离开／重载应在浏览器允许范围内提醒，说明硬关闭或存储被清除不保证恢复。
- 提问草稿以本机方式暂存，恢复时保留关联上下文，不触发发送。失败场景需通过可重复的存储故障注入验证；正式服务器网络断线恢复不属于本卡。

### R6：模拟定位与返回

- 使用明确标记的固定引用夹具，演示从原页选区跳转到另一页某个区域；无需真实 AI 或检索即可复现。
- 默认点击引用才跳转，突出目标区域；AI 临时指示与个人高亮在样式／标识上可区分，不混入笔记自动保存。
- 提供“返回原位置”，恢复原页、缩放、可见位置、选区、问题草稿与面板状态；本轮要求完成一次往返，不要求完整多级浏览历史。
- 无效页号、资料版本不匹配、区域不存在时禁止错误定位，说明原因并保留当前上下文；仅有可靠页码时允许明确的页级回退，不生成虚假精确框。
- 电脑右侧面板按需打开，可关闭，开关不重置阅读与批注。面板内容变长时保持输入与关闭入口可达，不遮挡必要操作。无需实现聊天生成、底部移动面板或拖动分栏。

## 6. 最小数据契约与职责交付

交付 TypeScript 类型及一个脱敏 JSON 示例，至少表达以下内容；允许调整字段名，但必须记录对应关系：

| 对象 | 必要信息 |
|---|---|
| 文档与预览 | 文档内容哈希／本地身份、原格式、预览格式、预览版本、页数、各页尺寸 |
| 定位锚点 | 文档／预览版本、页、坐标空间、区域列表、可选引用文本及锚点精度 |
| 批注 | ID、锚点、类型、笔迹点／高亮区域／贴条文本及位置、必要样式、修改时间、数据结构版本 |
| 阅读与提问状态 | 文档身份、页、缩放、可见位置、当前选区、面板开关、问题草稿 |
| 模拟引用动作 | 目标锚点、明确的夹具标记、跳转前返回状态；不得把任意 URL／代码作为执行动作 |

说明读取、坐标变换、选择、绘制、保存及面板各自模块职责。保存格式版本化，读取未知／损坏版本时提示并保留原数据，不静默覆盖。这里只约定未来可迁移的基础，不提前设计完整笔记数据库或 AI 工具协议。

## 7. 桌面环境与精度、性能标准

- 浏览器至少覆盖本机实际 Edge 与 Chrome 稳定版，记录精确版本；两者均需真实启动，不能只改 user agent。其余浏览器不作通过承诺。
- CSS 视口至少覆盖 1024×768、1440×900、1920×1080。阅读器缩放测 50%、100%、200% 与适应宽度；浏览器页面缩放在 100%、125% 各测一次关键定位。移动视口不在本轮矩阵中。
- 在同一页选择至少 3 个分布在不同位置的参考区域，保存后完成缩放、滚动、窗口调整、面板开关、翻页返回和刷新重开。比较区域四角／笔迹参考点映射后的显示误差，**最大不超过 4 CSS px**；报告测量方法、样本与最差值。不是只测变换函数的数学自洽，还需浏览器实际覆盖层与页面对齐证据。连续 10 次缩放往返后也须满足。
- 贴条锚点按上述精度保持；可读贴条布局若为避免遮挡而调整显示，应保留原锚点关联并说明，不能把界面避让当作笔记位置被篡改。
- 基准样本：本地、20 页以内、10 MiB 以内；记录机器、文档与冷／热加载。资源准备好后的热运行，翻页和缩放在 1 秒内稳定可读，笔迹反馈无持续超过 100 ms 的可见卡顿。加载与转换另记耗时，不把它们排除后宣称端到端达标；这些是本卡局部目标，不是生产 SLA。
- 一页至少验证 20 笔、10 个高亮、10 张贴条，检查选择、拖动、撤销和重开；不得因为只画一条线流畅便声明批注能力可用。

所有用例记录环境、样本 ID、实际步骤、预期、实际结果及证据路径。以下为强制最小集合，不以演示视频替代断言，也不以测试通过替代目视核对。

| 编号 | 操作与检查 | 通过标准 |
|---|---|---|
| A01 | 打开 S1，逐页导航；核对选定复杂页；对比原件哈希 | 页序正确，关键内容无丢失，原件未改 |
| A02 | 打开 S4 的预览，与原 PPTX 对比 | 逐页记录保真和转换依赖，人工步骤如实标识 |

| A16 | 性能样本与规定数量批注 | 记录局部耗时与观察结果，满足第 7 节目标 |
| A17 | 返回现有课程、资料和学习流程并执行项目回归 | 默认入口不被替换，已有流程无新增退化 |

证据至少包括：原件／预览对照截图、三种批注叠加截图、缩放和面板切换后的对齐截图、定位返回操作录像或步骤截图、失败恢复日志，以及机器可读验收结果。截屏应包含样本版本与页码信息，便于复核。

## 10. 完成、失败与回退判定

- **完整通过**：主格式的 R1～R6、数据契约、桌面矩阵与 A01～A17 均达到标准；PPTX 有可复现、保留关键内容的预览路径，人工转换可接受但必须明确。现有工程回归通过，证据齐全。仅说明技术可行，不等于生产功能或最终 UI 已完成。
