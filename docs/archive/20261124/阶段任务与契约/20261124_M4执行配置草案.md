# M4 执行配置草案

状态：已确认公开夹具与真实模型范围；配置 `m4-public-20261124-1` 已建立并完成一次预检。完整 R1～R8 仍未完成。

本草案只用于收集 M4 所需配置，不复用旧 FE-V10 账本、剩余额度或历史确认。确认后将生成独立版本号、隔离 SQLite、上传目录和 provider 账本。

## 待确认项目

| 项目 | 当前值 |
|---|---|
| 课程 | 待指定一门课程 |
| 资料 | 待指定 2 份脱敏且允许发送的真实 PDF；需列出允许页/片段 |
| 题目 | 待指定 2 道可由开发独立核对的真实题目 |
| provider / model | 待指定单一 OpenAI 兼容供应商与模型 |
| provider 尝试上限 | 待确认 |
| 总 token 硬上限 | 待确认 |
| 单次输入/输出上限 | 任务书默认输入 12000；输出需确认，未自动继承旧配置 |
| 费用 | 待确认；未知也必须明确记录 |
| 停止条件 | 私有泄露、虚构来源、关键知识错误、未知执行、预算到限、用户要求停止 |
| 隔离目录 | `data/acceptance-m4/<config-version>/` |
| 保留内容 | 原始请求、原始输出、provider 账本、SQLite、失败证据、截图与人工复核表 |

## 已知边界

- 不读取整门课程、个人全盘、未明确授权的资料、成绩、教师私有答案或账号信息。
- 不迁移正式数据库，不运行 FE-V10 保留集，不调用图片/联网能力。
- 真实运行按 R1～R8 顺序，每组完成账本与数据库核对后再继续。
- 任一硬失败或未知执行立即停止，不自动重试。

确认后再创建可运行的 `execution.json`；在此之前所有验证保持 Mock 或只读计划模式。
