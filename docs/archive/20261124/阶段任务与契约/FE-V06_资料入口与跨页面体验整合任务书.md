# FE-V06：资料入口与跨页面体验整合任务书

日期：2026-11-23（北京时间）｜版本：1.0｜状态：任务书已编写，开发待开始。

本任务落实用户对资料入口、前端风格和跨页面体验的整合要求。依据为[讨论记录](../原始讨论与设计/2026-11-22_资料学习工作区讨论记录.md)，前置能力见 [FE-V03](../实施验收与复核/FE-V03_实施与验收报告.md)、[FE-V04](../实施验收与复核/FE-V04_实施与验收报告.md)、[FE-V05](../实施验收与复核/FE-V05_实施与验收报告.md)。状态统一在[开发计划](开发拆分与PR计划.md)维护。

FE-V06 此前只被建议用作真实发送任务编号，未正式建卡；本次正式用于体验整合。真实 AI 发送另立后续任务，不在本卡实现。本轮只编写任务书，不表示代码开工或用户已认可最终视觉。

## 1. 问题、目标与范围

当前课程主站、阅读工作台和统一助手已有功能，但资料仍主要作为上传／解析对象呈现，阅读入口不突出；新旧页面视觉及返回语义不一致，助手常驻技术管理操作偏多。

本卡目标：让用户顺畅完成“进入课程 → 找到资料 → 阅读与批注 → 打开统一助手 → 返回资料列表 → 下次继续”，并能清楚区分阅读资料、练习题目和后台处理。复用已验收阅读器，围绕一条主路径完成有限整合，不重新设计全站。

| 本轮必须完成 | 明确后置 |
|---|---|
| 课程资料页的阅读优先信息层级、搜索筛选与主操作 | 全课程学习首页、考试时间规划、全站业务重构 |
| 正式课程阅读入口、返回与可追溯的继续阅读 | 自动 PPTX 转换、所有格式原生预览 |
| 主站／资料页／阅读器／统一助手的必要视觉一致性 | 全部校题、统计等页面的深度视觉迁移 |
| 助手低频管理操作整理、明确能力与保存范围 | 真实模型回复、联网检索、引用生成 |
| 必需的只读阅读摘要接口（若现有接口不满足） | 账号、公共部署、跨设备同步、笔记自动合并 |
| 电脑浏览器完整路径及已有保存／冲突机制回归 | 手机网页、原生 App、暗色主题完整实现 |

## 2. 开工与设计收敛

1. 核对当前代码、FE-V03～05 最后测试与未决试用项，记录实际 HEAD、源码指纹及未提交差异。不要将历史通过记录冒充本卡验收。当前存在大量未提交实现，保留并区分用户文档、前置实现与本卡改动，不清理或覆盖。
2. 用同一门有资料课程及一个空课程制作可操作整合样板，覆盖资料列表、阅读器及助手。先展示正常路径和一个失败状态，再评审入口、视觉及操作层级；不以多套配色长期并存代替收敛。
3. 用户评审前可继续接口、组件和回归准备；最终验收须记录用户反馈与处理结果，不能把本次“编写任务书”当作视觉认可。
4. 优先修复前置保存、恢复或身份隔离的实际阻塞；其余历史问题保持原记录，不借本卡扩为无边界重构。

## 3. 页面与交互要求

### I1：课程导航与正式入口

- 课程内明确提供“课程资料”和“练习题目”两个入口；可将原“开始学习”重命名为“练习题目”，其已有 learn 路由与会话恢复保持兼容，不改学习业务规则。
- 从课程列表显式进入课程、且没有指定子路由时，推荐进入课程资料；已有明确学习／历史／阅读链接优先，不因新默认入口重定向打断恢复。准确默认规则在实施设计中定稿并测试。
- 正式导航移除“资料阅读工作台 · 设计评审”式无课程实验入口。保留开发专用直达 URL 和测试复现办法，普通课程路径始终带正确 course／source 身份。
- 阅读页展示课程名、文件名与清楚的“返回课程资料”，返回对应课程；无课程实验页明确本机工作区，不伪造课程或自动上传本机记录。
- 资料／做题切换不丢已保存进度；未保存状态沿原保护处理。归档课程、来源移除及无效链接继续执行真实权限／生命周期检查。

### I2：资料页以使用资料为主

- 有资料时，顺序优先为可用的继续阅读、搜索／筛选及文件列表；上传收进“添加资料”次操作或可展开区域。统计、解析详情和网络补全按需展开，不挡在首批资料之前。
- 无资料时以上传为主，说明支持格式及当前阅读能力；首次上传完成后，提供进入该资料的明确动作，不让用户重新在多层入口查找。
- PDF 文件标题与主“阅读”操作均可打开对应课程阅读器；同名文件用真实类型、目录或其他必要信息区分。只读可用时不强制先执行 AI 解析。
- 文件行至少展示文件名、类型、阅读能力和相关处理状态。SHA、证据块计数、处理耗时等技术信息收进详情；错误若影响阅读或下一步操作必须直接可见。
- 提供文件名搜索及至少“全部／可阅读／需处理”筛选。搜索范围说明为文件名，不冒充全文检索；组合筛选、无结果和清除筛选可用，不因零结果展示课程无资料上传引导。
- 原有批量上传、文件夹导入、资料类型修改、证据核对、来源移除／恢复、下载原件及网络补全入口仍可发现并工作。使用频率不同可以调整层级，不能删除既有必要能力。
- 上传时可继续浏览原有列表；上传中防重复提交。个别文件失败不隐藏已成功资料，不以等待解析阻止阅读已有文件。

### I3：阅读能力与解析状态分开

- 阅读能力至少能表达可阅读、读取中／待确认、当前格式不支持和读取失败；AI 解析状态继续用已有真实字段，不能用“解析完成”推断原件一定能打开，也不能把“解析失败”一律当原件不可读。
- 对完整可读的 PDF，即使资料仍排队／解析失败，也应允许按生命周期规则打开。原件缺失、损坏、加密不可读或已移除时清楚失败，不修改成假成功。
- PPTX／DOCX 等当前不支持工作台阅读的格式提供下载／查看原件及明确说明，PPTX 可说明人工导出 PDF 再导入；不提供会打开空阅读器的主按钮。
- 避免每次列表刷新读取全部原件或解析全部 PDF 来判断能力。可以列表显示“PDF，打开时校验”，打开失败后给明确原因；确需健康元数据时走有范围的只读能力，不扩大为后台批处理。

### I4：继续阅读与真实恢复

- “继续阅读”仅基于成功保存的服务端阅读快照，显示真实文件和已保存页；没有记录时不占位伪造，不使用创建课程时间或猜测的最后文件。
- “最近保存的阅读”与“最近打开”语义区分：现有 updated_at 可能来自批注或阅读状态保存，若据此排序，应称最近保存／继续阅读，不声称精确统计最近打开。
- 摘要只匹配本课程、有效来源、对应原件 hash 与兼容预览版本；来源被移除、版本失效、文件不受支持时排除或显示可解释的不可继续状态，不跳错文件。
- 打开继续阅读恢复服务端已确认页码、比例与位置，保留笔记；不能仅显示页码但总是从首页打开。缩放／定位延续已验证能力。
- 页面刷新、浏览器前进后退以及从阅读返回时保留课程、资料搜索和筛选等必要视图状态。可使用路由参数／历史状态／按课程的本机 UI 偏好；换课程不串用筛选，读取 UI 状态失败不阻止访问资料。
- 不按同名文件合并记录，不将本机实验笔记暗中复制到课程服务端。

### I5：有限且一致的视觉规范

- 统一本卡范围内的应用头部、课程导航、资料列表、阅读外壳、助手、按钮、输入、提示和空状态；阅读器画布与原课件不随主题改色或重排。原绿色主站与蓝色阅读器的选择需在样板中收敛为一套强调色和语义角色，不能两个品牌并排。
- 用 BoardUI skill、实际组件源码与示例确定基础控件，复用已有免费组件；缺失时按需安装，保留来源／许可。不要直接全项目 init 或引入 Pro／整套聊天后端。
- 集中维护颜色、复合排版、间距、边框、圆角、焦点和禁用规则；类合并沿用 cx。笔记／课件内容的自定义颜色属于数据，不应被主题迁移覆盖。
- 用连续布局、分组与留白建立层级，避免上传、统计、阅读列表等同权重大卡片。正常页面不常驻大段工程说明。
- 先核对相邻 BoardUI 已安装 skill 与组件支持文件，不凭记忆写 API。设计中逐项列出组件映射、旧样式删除／保留范围及全局影响；禁止再叠一层全局 CSS 掩盖冲突。
- 旧页面暂不全面迁移，但共享外壳应一致；说明剩余边界。更新现有 design.md 作为唯一设计规范，不另立竞争性总规范。

### I6：统一助手的层级与简化

- 主站和阅读器都使用同一应用级入口；资料选择／题目关联只附加显式上下文，不生成另一个阅读器私有助手。开关面板不清空会话或改上下文。
- 主区优先展示真实能力状态、当前上下文／历史记录、草稿和当前允许的主要动作。当前无模型服务，保留“尚未连接 AI”及“记录问题，不发送”等准确表达，不能通过换名伪装发送成功。
- 本机／服务端模式切换、复制本机数据、导出原始 JSON、重载和预检等低频操作移入“会话与存储”等详情入口，保持键盘可达。模式仍明确显示，本机和服务端记录不能视觉上被暗示已合并。
- 保存失败／版本冲突直接提示并提供对应的重试、导出、重新载入等动作，不能为界面简洁隐藏在菜单中。正常状态不显示所有恢复按钮。
- 显式切换／复制的确认、归档只读、schema 错误保护、复制到非空会话限制、CAS、幂等保存及未保存内存保护全部保留；不能默认为用户切换存储位置或自动上传。
- 技术错误转为可理解的主信息，原始细节可展开；不要直接以 Error: 和服务端堆栈作为唯一提示。
- 题内原带学入口与重测同意继续可用。统一助手尚未真实发送这一限制说明清楚，不把“通用入口已统一”误写为真实带学已合流。

## 4. 数据与工程边界

### 必需只读摘要

如现有 API 无法提供继续阅读摘要，可新增一个课程范围只读接口或扩展已有列表响应。实施前定义请求／响应和兼容方式，至少包括 source ID、兼容版本标识、已保存页及更新时间等必要字段；不为展示摘要下载所有批注正文／原件。

- 读操作不得创建快照、修改 updated_at、更新课程学习状态或触发解析／模型。
- 服务端按实际课程／来源／版本过滤；归档只读、移除、永久删除策略与 FE-V03 一致；返回数据量有上限或分页，不通过逐文件 N 次原件读取拼装。
- 无记录返回真实空状态；摘要读取失败不阻断整个资料列表和手动阅读。来源随后失效时，打开阶段再次校验，摘要不是绕过正式读取校验的凭证。
- 不必为本卡新增 last_opened_at 或笔记表字段；若确有需求，另写原因、迁移／回退和最小范围，不静默扩大数据模型。

### 实现要求

- 前端文件可能涉及 App、SourcePanel、阅读外壳、统一助手及共享控件。先明确组件边界，不把入口整合变成复制第二套资料列表／会话状态。
- URL 迁移保持旧 course／source 链接和 learn 会话深链可用；不得依赖丢失后无法恢复的内存对象来构造返回。前端 hash 路由与独立阅读 HTML 共存可接受，不强制引入路由框架或合并全部构建入口。
- 复用 FE-V03～05 存储与身份契约，不变更正式学习规则、模型提示词、帮助记账或笔记格式。若不得不变更数据结构，明确兼容旧记录、冲突和回退，不清空命名空间。
- 阅读资源继续按需加载，默认课程列表不加载 PDF worker／完整阅读包；预取摘要不能触发收费解析。加载／请求可取消，快速切课程不得显示前课程结果。
- 测试在 Mock 与临时库中运行；私有资料只用于明确的本机验收，不写正式学习库，不调用模型，不推送／发布。

## 5. 验收规范

环境：实际 Edge 和 Chrome；CSS 视口 1024×768、1440×900、1920×1080；浏览器缩放 100%／125%。涉及阅读布局变化的操作继续满足 FE-V01 最大 4 CSS px 的定位误差要求。不是手机网页验收。

| 编号 | 场景 | 通过标准 |
|---|---|---|
| C01 | 空课程与有资料课程分别进入 | 空课程上传优先；有资料课程首个主要内容区可见实际资料／继续入口，无大块上传或统计挡在其前 |
| C02 | 文件名／阅读主操作打开 PDF | 进入正确 course／source；普通路径无需进入设计评审、本机选文件或技术管理界面 |
| C03 | 排队、解析失败但原件正常的 PDF | 可以阅读；后台状态真实显示，不误报解析已完成 |
| C04 | 损坏、缺失、不可读加密、已移除文件及不支持格式 | 不假装可读；错误／替代动作明确，不串资料，不反复无限重试 |
| C05 | 搜索、组合筛选、无结果和清除 | 匹配正确；无结果不冒充无资料，已有批注／会话不变 |
| C06 | 批量／文件夹上传与部分失败 | 原有能力保持，已有资料可继续访问，失败不遮住成功文件，上传无重复触发 |
| C07 | 无阅读记录与有成功保存记录 | 前者不伪造继续；后者显示正确文件、真实页码和有依据的时间语义 |
| C08 | 继续阅读，更新版本、移除后再进入 | 恢复实际页／比例／位置及笔记，失效摘要正确处理，不按名称猜测绑定 |
| C09 | 课程列表→资料→阅读→返回；刷新与前进后退 | 保持正确课程、可恢复筛选与阅读记录；有未保存内容时按原规则保护 |
| C10 | A／B 课程快速切换与摘要请求失败 | 不串课程、不被旧响应覆盖；摘要失败仍能浏览资料和手动阅读 |
| C11 | 默认入口、原 learn／session 深链及历史阅读 URL | 默认规则清楚，旧链接仍有效；正式导航无无身份实验入口 |
| C12 | 主站／资料／阅读／助手同屏与往返 | 颜色角色、字体、按钮、边框、提示与导航语义一致；原课件与用户颜色不变 |
| C13 | 助手正常模式与管理详情 | 主要区突出上下文、记录、草稿；低频操作集中可达；无模型／保存范围准确 |
| C14 | 本机↔服务端、复制、全新浏览器恢复 | 仍需显式选择，无暗中迁移；已有数据不覆盖；恢复来自正确存储而非伪造缓存 |
| C15 | 服务端 409、断网、超时、旧格式与归档只读 | 草稿保留，错误及恢复动作直接可见，保存回执语义保持，不能盲目覆盖 |
| C16 | 1024／1440／1920 与 125% 缩放；键盘／中文输入 | 无应用横向溢出、控件重叠或错误被裁切；焦点可见合理返回，编辑不误触快捷键 |
| C17 | 阅读工具与三种批注、选区与助手开关 | 原功能不退化、坐标精度达标；上下文和草稿保持，无新增模型或学习副作用 |
| C18 | 摘要接口如新增，实际临时 API 联通 | 无写入／模型副作用、范围校验正确、无 N 次原件全读取；不只依赖模拟接口断言 |
| C19 | 全量受影响回归、构建与默认资源检查 | 必选测试通过，列表不加载阅读大包，真实能力边界和旧页面无新增退化 |
| C20 | 用户完整路径试用和设计评审 | 记录用户实际原话／卡点、对应处理和仍待反馈事项，不编造满意度或无提示成功 |

C18 仅在没有新增／变更摘要接口时可注明不适用并说明替代数据来源，C07／C08 不可因此省略。“首次打开文件后再返回”不替代冷进入课程的继续阅读验证。

- 从课程资料列表打开受支持文件，点击标题或主操作一次即可进入阅读器，不再经过选择本机文件或二次导入。
