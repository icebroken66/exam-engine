# FE-V03 课程资料接入与阅读笔记持久化

2026-11-23，用户接受FE-V02当前体验并授权继续后续。沿既有顺序实施电脑课程PDF接入与服务端保存；真实AI、手机、自动PPTX转换、题目判分及帮助记账不在本卡。

## 契约

- 课程资料列表提供阅读入口，携带courseId/sourceId，以后台资料身份与SHA-256校验原件。工作台通过既有文件下载接口读取，不要求重复上传；不能仅凭文件名匹配。其他格式保留原流程和人工PDF提示。
- 实验入口继续本机IndexedDB。课程模式明确服务端保存，独立命名空间；本机旧笔记不自动上传，不覆盖或删除。
- 服务端按课程／source／原件hash／previewVersion存schema1快照，含原归一化批注与阅读状态，服务端修订号CAS防止多窗口覆盖。冲突保留内存与可导出副本，重新载入服务器版本须显式操作。
- 请求校验页码／坐标／颜色／有限数值／长度与总大小；资料移除、缺失、课程不匹配与版本不兼容明确失败。移除保留笔记，永久删除课程清除对应记录。归档课程拒绝新增修改。
- 网络失败保留当前笔记，显示失败并提供重试／JSON导出，离开时提示未保存；不虚构离线可靠恢复或跨设备自动合并。服务端成功后跨刷新／重新打开恢复，不以本机缓存当服务端成功。
- 只添加独立笔记表及明确路由，不修改正式成绩／教学规则，不调用模型；测试只运行隔离数据库。启动按既有create_all添加新表，回退保留新表及用户数据。
