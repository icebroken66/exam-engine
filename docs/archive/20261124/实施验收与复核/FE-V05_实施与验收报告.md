# FE-V05 实施与验收报告

2026-11-23。课程统一助手服务端快照及发送前预检已实现，工程通过，待用户试用。真实模型发送未启用，本轮没有模型调用。

## 使用路径

进入课程或课程PDF→AI学习助手→打开服务端助手会话。默认仍保留本机模式，显式选择后本浏览器记住该课程模式。新浏览器需自行选择服务端模式，随后可读取同一服务端课程会话。无课程工作区继续仅本机。

- 服务端模式按课程保存统一草稿、关联上下文和提问记录；350ms停止编辑后开始保存，成功回执后才显示已保存。不是聊天机器人回复。
- 本机和服务端记录独立。复制本机记录到空服务端会话需显式确认，原本机记录不删除；服务端已有草稿／上下文／记录时禁止整份覆盖，暂不提供自动合并。
- 失败保留内存，可重试或导出当前内容；冲突409停止写入，先导出再显式重新载入服务器版本。旧记录格式不兼容时禁止编辑，仍可导出服务器原始响应。
- 同窗口切换页面／课程时保留未保存内存；刷新或硬关闭不能保证恢复未保存内容，浏览器允许时提示离开。请求20秒超时。保存进行中继续输入会在前次回执后补存最新状态，不回写旧文本。
- 已关闭面板时，显式关联资料／题目可重新打开服务端助手；上下文不会因换页而自动替换。

## 服务端契约

GET／PUT /api/courses/{course_id}/assistant。新增assistant_snapshots，course_id唯一，保存JSON快照、revision和更新时间。客户端提交expected revision形式的revision与同号快照；SQL条件更新和唯一键约束阻止多窗口覆盖，完全相同快照在丢回执后幂等重试。记录最多200条，草稿10000字，快照5MiB，校验schema、课程、上下文形状、坐标、重复ID等。

归档课程读取只读，写入和预检拒绝；课程永久删除时清除新表行。来源移除不删除历史上下文快照，但实际发送预检拒绝该目标。服务端快照保存历史用户片段，不将其标为已核验来源。

POST /api/courses/{course_id}/assistant/preflight只做预检：

1. 资料：核对课程归属、source未移除、原件hash／preview版本、实际原件存在、可读PDF与页数、区域合法；选择文字仍是用户片段，未独立核验，也不执行OCR。
2. 题目／答案：核对课程、session、当前task、progressVersion、stage、来源未移除；答案要求存在已提交作答。返回use_tutoring，必须沿原带学接口进行求助及重测同意。本轮不接受客户端片段为教师答案或判分依据。
3. 无关联内容：只验证问题格式。所有成功响应均canSend=false、modelCalled=false；UI明确不调用模型。预检不创建UsageRecord、LearningEvent或帮助暴露。

真正发送的后续契约：服务端持有会话序号与幂等request_id、同一请求只生成一次；每条输入冻结选定上下文，生成前后复核来源／题目版本；模型用量和生成状态可恢复；只允许有效证据ID且展示来源支持程度。题目求助复用原带学生命周期、重测同意和帮助记录，不能用通用聊天绕过；预检通过不代替这些生成时检查。真实发送接口本轮尚未新增。

## 迁移、回退与限制

新版后端启动沿既有create_all增加独立表，本轮只对临时库执行，不在正式库直接运行迁移。用户需重启新版后端。回退保留assistant_snapshots及本机exam-engine:assistant:v1记录，不删除用户数据。正式备份仍应包含整个数据库及资料原件。
