# M3-alpha 二次独立复核结论

日期：2026-11-24。复核M3-01预算修复、相关测试、构建和实施报告。未调用真实模型、未发送个人资料、未迁移正式库。

## 结论

**M3-alpha 隔离工程实现通过。** M3-01已按回答模式修复，并有专门回归测试证明预算差异。该结论只覆盖alpha的Mock／确定性工程范围，不代表真实模型质量、真实资料效果、M2全部视觉矩阵或最终产品完成。

## 独立验证

- 检查 `backend/app/assistant_generation.py`：预算预检在生成前根据 `r.intent.answer_mode` 选择 `max_tokens`，短答使用 `OUTPUT_LIMIT`，完整讲解使用 `COMPLETE_OUTPUT_LIMIT`；网关仍按同一实际值最终reservation。
- `backend/tests/test_assistant_generation.py`：全部通过，包含额度只够短答、不够完整讲解的回归；短答派发，完整讲解被预算保护拒绝。
- `backend/tests/test_assistant.py` 与 `backend/tests/test_model_gateway.py`：相关测试全部通过。
- `npm test`：12个测试文件、56项通过。
- `npm run build`：通过。
- 后端全量此前279项通过；本轮未因M3-01重复全量运行，保留该证据的时间与范围限定。

## 通过范围

1. 短答／完整讲解意图可区分并冻结在请求中。
2. 完整讲解使用6000候选输出上限，短答使用1500；短答不会因完整讲解档位不足而被错误拦截。
3. 续问创建新的request_id并关联已发布父回答；父请求上下文只读，跨Topic／未发布父级被拒绝。
4. 查看、展开、引用定位和重读不产生新模型生成；服务端状态、来源、帮助和上下文隔离沿既有契约。

## 未包含在本结论

- 真实模型与真实课程资料质量；6000不是最终产品长度保证。
- 原生125%、完整Tab／Escape／焦点、中文IME、PDF像素级保真、真实迟到模型事件。
- 图片／纸笔、联网、跨资料自主检索、永久贴条、双向链接、多Agent。

## 下一步

M3-alpha可以进入后续隔离浏览器／交互回放和任务书中的未覆盖工程项；是否进入M4真实模型／真实资料验证，需要另行确认素材、模型、预算和停止条件。不要把本结论写成FE-V10整卡完成或最终产品验收。
