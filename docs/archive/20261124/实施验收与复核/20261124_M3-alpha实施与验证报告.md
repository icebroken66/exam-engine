# M3-alpha 实施与验证报告

日期：2026-11-24（北京时间）  
依据：[M3-alpha 任务书](../阶段任务与契约/20261124_M3-alpha长解释与学习对象关联任务书.md)

## 本次交付

- 请求契约增加 `answer_mode: short | complete`。短答沿用既有输出上限；用户点击“完整讲解”时使用长解释上限，仍由服务端决定预算。
- 请求契约增加 `continuation_of`。继续追问创建新的 `request_id`，服务端只接受同一对话中已发布的父回答，父回答内容和冻结上下文保持只读。
- 前端统一助手入口增加“完整讲解”按钮；已发布回答旁增加“继续追问（新请求）”入口。查看、展开、引用定位仍只读，不重新生成。
- 服务端公开状态带回 `answer_mode` 与 `continuation_of`，历史消息继续使用原有 `text/claims` 单一正文存储；旧记录仍只读兼容。
- 保留既有题目／资料隔离、页级 DocumentAnchor、任务级 TaskAnchor、来源版本复核、失败／取消／未知执行和导出能力。

## 已验证

- `npm test`：12 个测试文件、56 个测试通过。
- `npm run build`：TypeScript、Vite 构建通过。
- `.venv\Scripts\python.exe -m pytest -q backend/tests/test_assistant_generation.py`：全套生成生命周期测试通过，含新增完整讲解与续问新请求隔离断言。
- 新增断言覆盖：完整意图由服务端写入并传给 Mock provider；长解释预算由服务端选择；续问使用新请求并保留父请求关联；历史形成独立 user/assistant 对，不复用旧请求。

## 证据边界

本轮只使用隔离 Mock 和本地测试，没有调用真实模型、发送个人资料、迁移正式库或增加真实调用预算。测试通过表示契约和状态回放成立，不代表真实模型语义质量或真人学习效果已确认。

## 并行未验证项

原生浏览器 125% 缩放、完整 Tab/Escape/焦点矩阵、中文 IME、PDF 像素级保真和真实迟到模型事件回放继续标记为“未验证”，不作为本 alpha 的阻塞门槛；进入真实资料/模型验证前需单独补证据。

## 回退说明

停用完整讲解或续问入口时，保留已生成请求、消息、来源核验和导出数据，历史只读可读；回退不删除解释记录或用户内容。

## M3-01 修复

独立复核发现预算预检曾对短答错误地预留完整讲解额度。现已按 `answer_mode` 选择预检上限：短答使用 `INPUT_LIMIT + OUTPUT_LIMIT`，完整讲解使用 `INPUT_LIMIT + COMPLETE_OUTPUT_LIMIT`；网关仍按实际输出上限做最终预留。新增预算差异回归已通过。

## 当前状态

M3-alpha 实现与 M3-01 修复及隔离工程验证已完成，状态为“待独立复核”。M3-alpha 通过不等于 M4 真实模型验证，也不等于最终产品完成。
