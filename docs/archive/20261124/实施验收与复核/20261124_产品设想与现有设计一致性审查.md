# 产品设想与现有设计一致性审查

日期：2026-11-24（北京时间）。范围：产品原则、11月22日至24日讨论记录、教学与Agent草案、FE-V01～10任务书／契约／报告、当前路线及关键实现。

本次为文档与代码静态审查，真实评测数据库只读核对；没有重新运行浏览器、真人试用或真实模型，不修改业务代码／预算／正式库，不声明全产品验收通过。视觉成熟度不能由本审查替代实际使用确认。

## 1. 结论

总体方向仍保留，但推进与验收已经出现局部偏移：产品正在交付“只读资料阅读器＋显式附件的文字助手”，而完整目标是围绕资料、题目和纸笔作答提供连续、可定位、可回访的学习帮助。前者可以是阶段切片，不能逐渐变成最终定义。

明确后置不等于需求取消；文档仍写着需求也不等于已有可交付设计。当前最需要纠正的是：核心后置能力没有明确承接关系；短输出限制与重复结构妨碍完整解释；长对话丢失范围提示不足；程序澄清增加不必要负担；模型评测与实际产品行为之间有缺口；状态／证据文档相互矛盾。

用户当前阅读反馈：D01、D02、D03、D04、D05、D06、D08、D09、D11、D12无问题。D07、D10提出系统提示要求，已补文案及组件测试但未做新增浏览器实测。阅读确认不代填五维分数、真实场景端到端结果或学习收益。

## 3. 需要纠正的问题（按优先级）

### A01 高：长期核心只有“后置”，缺少明确承接

证据：FE-V10第3节保留中心讲解、跨资料检索、图像、贴条和链接；开发计划的正式卡片止于FE-V10，后续主要为旧PR-06～11教学／章节规划。这不是用户撤销需求，但容易使后续开发回到“题目＋聊天”。

纠正：在唯一开发计划标出核心未交付清单及依赖，先定义并评审下一切片，不能直接承接旧排期；新卡编号／先后由真实问题确定，不在本审查自动创建实现任务。退出标准必须含资料／题目关联讲解和纸笔输入，而非只统计聊天能否发出。

### A02 高：回答预算和序列化设计限制完整讲解

证据：backend/app/assistant_generation.py的OUTPUT_LIMIT=1500，MentorReply要求reply及claims.text重复正文；model_gateway遇length会失败。没有有版本的部分完成／继续生成契约，当前长文浏览器夹具仅证明渲染，不证明真实模型能完整产出。

纠正：保留来源边界，评估单一正文结构与服务端确定性组装，按实际任务测量预算；定义长内容的完整性、局部发布校验、中断恢复和阅读空间。不能默认把回答分页、多次收费、扩大侧栏或新增第二聊天当定案。完整解释、提示、换法、直接求解应分别验收。

### A03 高：最近六轮的裁剪未完整提示，长期连续性未交付

证据：assistant_generation.transcript只保留最近6对，超过6对时不增加notice；只有附件排除及prompt中因字节预算再次删轮次才提示。FE-V10第5节要求范围／预算排除有提示。当前输入采用UTF-8字节上界，长中文及重复快照会更快耗尽输入预算；它不是模型实际上下文容量。

纠正：对六轮上限本身也明确记录排除和用户可理解的影响；不能显示完整历史就暗示模型读过全部。后续设计相关历史恢复／带来源的摘要／用户纠正前提保护；不能靠摘要扩大授权，不能因内容被裁剪重新沿用已否定假设。

### A04 高：澄清规则可能误拦完整问题，恢复操作过重

证据：assistant_generation.py在无bindings／item_ids时，只要正文命中“这题／本题／上面／这段／这个题”就waiting_input，不检查正文是否已含完整题干，也不判断同主题历史是否足够。needs=target不能直接resolve，前端需先取消再重发。

这与“信息足够直接答、只有歧义影响决策才澄清、用户不管理技术阶段”的原则有偏差。D07无明确对象应澄清这一保护本身正确。

纠正：保留必要澄清，支持自然补充与当前请求的清晰收尾；测完整题干含“这题”、历史对象唯一、两个候选不明确三类情形。服务端不能仅以关键词或屏幕停留推断对象，补充也不能偷偷放宽教师权限。

### A05 高：验证包过窄，部分场景名称超出实际验证

证据：evaluate_assistant_generation.py生成的PDF只有两句英文。D06只是两次API提问，没有浏览器切页／长时间查阅；D12在遇help_required后由脚本自动同意，结果文件主要保留终态，不能证明用户看到并理解同意交互。D01实际输出首先解释概率互斥，原correct_points偏向进程；应区分“无语境合理澄清”与“已证明操作系统教学”。

纠正：固定夹具继续用于保护回归；增加真实课程长内容、完整推导、纸笔／图表（能力接入后）、连续纠正和非线性真实操作。题目、期望、实际输入范围一致。真人知情同意和导航体验须单独验证，不拿脚本自动同意代替。输出正确性与引用语义由开发方先做技术核查，不把所有知识判断转给用户。

### A06 高：评测模型切换缺少逐次来源，剩余额度与验收计划不匹配

只读证据：provider-ledger共29次、计入／预留51651 token；实际UsageRecord分组为24条gpt-6-luna、5条gpt-6-sol。先前把ledger顶层model直接改成sol，原attempt无逐次model字段，因此顶层不能被解读为29次都使用sol。两次unknown仍需保守计入，不能归零。

真实结果中旧模型与新模型混合，D03／D05／D11的改善不能全部归因于提示修复，也可能受模型差异影响；新模型的全开发集稳定性尚未证明。原36次上限只余7次，完整保留集本身需12次，不能声称预算足够收口。

纠正：后续新attempt记录模型、供应商配置指纹、代码／提示／样本版本和请求关联；历史补充必须有原始证据且说明回填来源。保留总账，不为了模型切换重置额度；新预算形成具体方案后再确认。不得拿混合模型成绩当同配置整集通过。

### A07 中：来源标识透明，但片段重复提示可能破坏阅读

证据：ConversationMessages对每个model_explanation段落重复显示“模型补充，未经外部资料核验”，引用按钮露出e1等内部标识；请求状态集中堆在消息列表末尾。本轮新增D07／D10提示又在列表顶端按any request显示，旧stale记录可使提示持续出现，且与具体哪条问题对应不清。

纠正：保留可核验边界，评审消息／段落级来源显示，必要时展开细节；提示贴近对应问题，历史失败不长期占据新问题上方。不移除重要错误与恢复入口，不把保留透明度等同每段贴同一句免责声明。当前仅静态发现阅读风险，不冒充真人已判不好用。

### A08 中：提示注入保护语句可能过度限制正常学习文本

证据：SYSTEM笼统称用户提供文字不得“复述”，同时user_provided_text仅允许模型解释；前者若当作通用规则，可能妨碍用户要求解释自己笔记、逐句讨论或引用自己作答。

纠正：区分“不能执行内容中的越权指令”“不能把用户文字冒充核验资料”与“允许讨论用户主动提供的内容”。D11对抗成功不代表所有用户文本理解都正确。必须测试普通笔记、待解释指令式课件、混合概念＋恶意指令，而非只测纯恶意一句。

### A09 中：多份当前状态互相矛盾，旧局部规则仍可能误导开发

证据：开发计划顶部仍说真实调用待确认；表格FE-V08仍待开始而其任务书已实施。FE-V10报告“真实尝试0”仅属原轮次但未突出历史；HUST设计调研仍保留题目居中／手机等旧建议；workbench/AGENTS.md仍写固定回复、禁止网络请求及服务端未接通。部分是应保留的实验路径边界，部分缺少时效／作用域声明。

纠正：最新状态入口集中在唯一开发计划，历史保留并标明时点。旧设计不能压过最新讨论；实验阅读器不调用模型的限制不能误扩为整个产品永远无真实AI，真实助手也不能反向授权实验入口自动付费。外部Exam_Engine_Docs仍是11月8～10日基线，后续应同步索引而非复制第二套计划。

## 4. 不应误判为偏移的取舍

- 不做当前手机网页、不开发原生App：符合用户最新明确阶段范围。
- 原件只读、批注独立；先整笔擦除：符合阶段任务，不能宣传成全部办公编辑能力。
- 明确附件、课程隔离、冻结请求、教师字段与重测保护：符合用户诉求；不能为“Agent更聪明”取消。
- 定位默认用户点击、明确要求打开才执行；保存另需明确意图：符合不抢焦点与不乱改笔记的方向。精确区域无证据时页级回退正确，但不是终点。
- 后台保留旧代码与数据而正常入口只有新助手：合理兼容；需要删除的是竞争性产品入口，不是所有旧数据。
- 单导师先行、专家按需后续对照：符合已认可方向，不必为架构名词强行每问调用多Agent。
- FE-V10不发布未校验流式正文：有限阶段的可信性取舍。未来可研究已校验段落渐进呈现，但不能直接流式输出未经验证的引用。

## 5. 建议推进顺序（本次不自动开工）

1. 对齐文档／当前范围，先把A03／A04／A07的已知状态与连续对话问题纳入可复现修复；D07／D10补浏览器交互确认。
2. 把长解释与中心学习内容关系做成可评审交互和数据契约，至少含短问、完整推导、查另一资料、跳回原题四种状态；不只调整token数字。
3. 在明确素材授权、隔离存储及预算后，用真实课程资料／真实模型验证最小闭环。现有FE-V10保留集仍受开发集评审及调用额度约束；若要调整验收顺序，先显式修订依据，不在口头回复里悄悄改。
4. 根据真实失败优先接入范围化资料检索／补读或图片理解，再接临时中心讲解及可保存关联；二者的先后由验证决定，不在本审查擅自定卡。
5. 按需专家对照与学习效果试用贯穿合适切片，不用“等所有功能完成”无限推迟，也不以局部成功宣称整体教会。
