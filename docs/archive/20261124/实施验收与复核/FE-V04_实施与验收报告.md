# FE-V04 实施与验收报告

2026-11-23，用户继续授权。本阶段统一助手入口、按课程的本机会话、显式资料／当前学习题／已提交作答适配已实现，工程通过，待用户试用。不代表真实AI或全软件服务端对话已实现。

## 实际行为

- 主应用头部和课程阅读工作台均可打开AI学习助手。主应用无课程时使用独立工作区记录，进入课程后按课程隔离。课程资料和学习页切换恢复同origin浏览器里的统一草稿与提问记录。
- 资料框选／选字后点击向助手提问显式关联当前选区，保留hash、source、previewVersion、页码和归一化区域。换页或打开其他资料不自动替换。
- 当前学习题提供将本题关联到统一助手；已判分作答提供将已提交作答关联到统一助手。只复制题干／选项或已提交作答和已显示反馈，不复制未展示参考答案，不读取正式作答草稿。
- 每条本机提问记录冻结当时上下文，清除或替换当前关联不会改历史记录。明确未连接AI，按钮为记录问题（不发送AI），无虚构机器人回复。已有带学交流和独立重测转带学同意流程保留，不借统一记录写入帮助或评分。
- 课程PDF旧问题草稿仍在资料旧草稿中，继续随服务端笔记保存；显式带入才写统一助手，已有统一草稿时确认替换，取消保留原内容。旧实验入口仍用于历史验收。
- 本机会话按课程localStorage持久化，200条记录及10000字草稿上限，失败保留内存、重试／导出、未知格式不覆盖。跨窗口变更事件及保存前原始值检查会阻止已检测冲突；本地Storage没有事务CAS，不宣称同时写入具有服务端级原子保证。服务端会话同步后续实现。
- 保存失败的草稿在当前页面内课程切换后仍可恢复；刷新或硬关闭的未保存内容不保证，浏览器允许时显示离开提醒。清理本机存储会丢失已存统一记录。导出为备份，当前无JSON导入覆盖按钮。

## 结构与边界

src/assistant/session定义类型、校验和显式关联事件，UnifiedAssistant持有会话，App及Review仅装配入口和容器。ReaderLab继续拥有唯一阅读与批注状态；统一会话不复制PDF页码滚动。上下文是历史快照，显示旧任务／版本，不暗中跟随当前页面。

新增样式仅作用.ua-*、.app-unified-assistant及局部布局，工作台颜色复用--wb角色，无全局重置；未更改旧应用配色。无包依赖、模型、数据库或新后端路由。原有服务端笔记与统一会话的保存位置在界面分别说明。

本轮不承诺跨设备、账户、跨origin／端口恢复；真实AI、资料检索、引用跳回精确选区、统一会话服务端存储、通用助手和当前题帮助记账合流均未接入。现有带学保持其独立真实接口与恢复契约。
