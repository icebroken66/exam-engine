## 使用路径

按原README启动后端与网页（npm run dev），进入课程→课程资料→PDF旁的阅读。无需重新选择本地原件；链接携带课程及资料ID，打开前校验文件内容hash与页面尺寸。顶部返回课程资料。PPTX继续人工导出PDF后作为PDF资料导入。

- 课程入口：/reader-workbench.html?course=<courseId>&source=<sourceId>。
- 不带身份参数仍是独立本机验证入口；原IndexedDB数据保留，不自动上传到课程，不按文件名猜测归属。
- 新增GET／PUT /api/courses/{course_id}/sources/{source_id}/reader。服务端保存三类批注、阅读页、比例、滚动、关联上下文和当前文档草稿。
- 只在服务端事务成功并收到回执后显示已保存。断网保留内存，可重试／导出。刷新可恢复已成功保存的数据，未保存的硬关闭内容不保证恢复。
- 多窗口以revision条件更新，冲突409而不覆盖。先导出当前JSON，再显式重新载入服务器版本。丢失回执后相同快照重试幂等。网络请求有超时，不无限等待。
- 外层助手保留，无模型请求。草稿当前仍按资料保存，不是全软件跨题目统一会话。

## 数据与兼容

新增reader_snapshots表：source_id＋preview_version唯一，记录source_sha256、revision、schema1快照与更新时间。启动沿用Base.metadata.create_all建立新表，不修改已有表字段；本轮仅在隔离测试库执行启动与联通，没有运行正式学习库迁移。用户正常重启新版后端时创建表。

后端逐项检查课程归属、资料未移除、PDF原件存在／SHA-256一致、预览版本、实际页尺寸、坐标与页码、颜色、数据大小及字符串长度。归档课程可读但拒绝保存；移除资料后保留笔记且拒绝访问；恢复后可读。永久删除课程时明确清除阅读快照。旧预览记录不迁移，新预览版本独立存储。

新增reader_routes负责HTTP与快照校验，models只增加独立模型；main只注册路由、允许PUT并在永久删除流程清除新表。前端courseStorage负责课程文件加载与CAS；ReaderLab复用原唯一文档／批注／历史状态，通过存储适配切换，未重写坐标层。SourcePanel只新增PDF阅读链接。开发及preview都代理/api；正式部署仍需同origin反代现有API。

本项目保持本地单用户部署范围，服务端保存指当前运行服务及其数据库，不代表公共云、多用户权限隔离、自动备份或已完成跨设备部署。不运行收费解析或真实模型。
