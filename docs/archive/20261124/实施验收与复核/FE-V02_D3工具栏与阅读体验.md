# FE-V02 D3：工具栏与阅读体验

2026-11-23，北京时间。用户确认继续D3后实施。此文记录本次增量，不替代FE-V02总报告或FE-V01未收口验收。

## 用户反馈及本轮范围

用户认为按钮样式粗糙，要求参考WPS／Word／PowerPoint或开源工具；观看体验缺少连续缩放、充分利用屏幕。随后确认进入D3。本轮收敛顶部工具栏，移除常驻A/B与重复标题，不继续保留两套产品结构。统一助手保持外层入口，PDF中仅保留选区附带上下文动作。

## 实现

- 工具分为导航、模式、批注、历史、显示、阅读视图；图标+文字，细分隔、轻量悬停、清晰选中，不再每个动作都是厚重的边框按钮。笔色／笔宽仅笔刷模式显示，窄阅读区将低频文字折为带可访问名称的图标。
- 页码与缩放移到底部固定视图栏。10%～400%连续比例，支持百分比输入（如137%）、1%步长滑杆、加减、Ctrl/Cmd+滚轮按指向区域缩放。滚轮不改浏览器缩放，只改变课件比例；普通滚轮继续滚动。
- 首次新文件适应整页，横版／竖版均以可用区域计算并居中；适应宽度单独提供。用户设定的数值比例不随助手开关改变。fit／page自动随可用区域变化。保存恢复支持任意有效比例，旧50/100/200%及fit仍兼容。
- 专注阅读暂收起顶部、导航与助手，保留退出与底部翻页缩放；Esc退出并恢复此前导航、助手、比例、滚动。原生全屏使用Fullscreen API，成功后才进入专注；失败显示原因，可改用专注。浏览器退出全屏后恢复视图。
- PDF、文字层与批注仍共用同一显示比例；原归一化锚点不修改。大页面栅格设置1600万像素预算防止400%与高DPI叠加爆内存，CSS尺寸和坐标不变；超预算时清晰度有限，不宣称无限高分辨率。
- 连续缩放边界集中于view.ts；ReaderToolbar/ViewControls独立展示组件；PDF核心保留在ReaderLab。没有新增运行时依赖、模型或上传服务。PPTX仍需人工导出PDF，不包含动画和原生编辑。

## 来源与取舍

本次在线查询PowerPoint官方缩放／适应窗口及阅读视图帮助，并查看PDF.js官方viewer。参考的是工具分组、适应窗口、缩放与专注阅读的交互，不复制微软图标、品牌或源代码。参考地址：

- https://support.microsoft.com/en-us/office/zoom-in-to-a-part-of-a-slide-in-slide-show-view-f97a0e8e-0b64-4c8b-a0e3-680615b2ad80
- https://mozilla.github.io/pdf.js/web/viewer.html

视觉基础仍用实际BoardUI Button；仅通过范围内className组合和集中CSS定义工具样式，图标使用已有Remix Icon。无新组件库、无全站init、无preflight。workbench.css完整替换上一版展示样式，未叠加第三个全局样式文件。没有把Word／WPS完整办公功能作为实现承诺。
