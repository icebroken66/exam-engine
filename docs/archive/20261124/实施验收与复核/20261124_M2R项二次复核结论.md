## 证据边界

- `m2-browser.json`的B5断言包含`data-pdf-loaded`、iframe来源／页码和文本回退，但当前源码的回退文本是夹具字符串；不能把它解释为PDF文字提取或PDF.js像素成功。
- `m2-layout-matrix.json`准确标注Edge默认100%，不覆盖浏览器原生125%、键盘、中文组合输入或真实ReaderLab坐标。
- `npm run build`本轮通过；前端25项与R项脚本的“通过”沿提交方记录，未在本轮重新运行完整测试。旧后端279项／全套UI历史边界保留。

## M3准入结论

当前允许继续做无付费的M2收尾准备和契约核对，不允许进入真实模型接入或正式库迁移。M3进入条件至少包括：

1. Edge／Chrome或明确限定的浏览器上完成原生100%与125%，并记录1024／1440／1920及关键长公式／表格状态；
2. 键盘Tab顺序、关闭焦点返回、Escape、中文组合输入有可重复回放；
3. PDF像素渲染有真实可观察的ready／failed证据，或明确把本阶段能力限定为字节读取＋文字夹具，不将其宣传为PDF阅读验收；
4. 迟到事件至少以确定性夹具验证目标request／topic不污染题B，不能只显示静态说明；
5. 修订包与M2总评审包状态对齐，保留“样板通过／正式能力未实现／未运行”三类边界。

满足上述条件后，再由用户确认M2方案是否可进入M3；本结论不代替用户的视觉与操作签收。
