# FE-V04 统一助手会话与上下文适配

2026-11-23，用户继续授权。实现应用壳统一入口、同课程跨资料／学习视图草稿与对话记录、显式资料选区／题目／已展示作答上下文。先完成不调用模型的交互契约；保留已有正式带学与帮助记账，不将通用记录按钮包装成发送AI。

本阶段统一会话暂存在同origin浏览器，与服务端阅读笔记分开。明确本机范围、导出、存储失败和其他窗口冲突；不同课程隔离，未知格式不覆盖。旧文档草稿不自动导入，只可显式带入。资料切换不暗中替换上下文；每条记录固定当时上下文。真实模型、服务器会话同步和来源检索另阶段接入。

课程阅读使用统一助手；无课程实验入口保留FE-V01／02复现。当前题提供显式附带入口，不读取未展示参考答案或自动附带正式草稿。已提交答案上下文只提供用户作答与已显示反馈。通用助手不调用tutoring、评分、提交或帮助接口，独立重测仍通过原带学同意流程求助。

验收：同课程资料→课程→做题恢复统一草稿与记录；切课隔离；显式上下文替换／清除；记录快照不变；坏存储、写失败与多窗口冲突可恢复；旧学习和reader回归。工程通过与用户试用分别记录。
