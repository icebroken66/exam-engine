# M2 R 项最小修复与验证记录

二次复核：[M2 R项二次复核结论](20261124_M2R项二次复核结论.md)。R2／R3／R4在样板范围达到通过，R1／R5部分通过；100%桌面矩阵有限通过，125%／键盘／IME／像素／迟到事件仍暂缓。M2未整体签收，M3继续等待。

日期：2026-11-24。范围限于二次复核提出的 R1～R5；M3 仍未开始，未调用真实模型。

## 已修复

- **R1**：PDF 样板由写死 loaded 改为按实际 `fetch` 读取公开 PDF 字节后进入 ready；loading／failed／ready 均可见。失败不显示 ready。文字回退明确标为 PDF 文字层夹具，不冒充模型或服务端提取。
- **R2**：来源有效性按 source 索引保存；返回资料 A 不会复活资料 B 的失效状态。失效后定位按钮保持禁用。
- **R3**：解释目标冻结在 `explanationTarget`，视图切换不改变解释归属。题目 B 查阅资料后仍显示 B 的“尚未提供本题讲解”；A 解释只能在 A 目标下主动查看。
- **R4**：本轮精度收窄为可实际支持的 `DocumentAnchor.precision='page'` 与 `TaskAnchor.precision='task'`。文字／区域／步骤精度留待后续，不再用缺少载荷的类型宣称支持。
- **R5**：补充个人笔记层、临时定位标记、独立笔记开关、继续追问输入，并为这些状态增加浏览器断言。其空间关系仍是样板级图例，不冒充正式批注系统。

## 证据

- `scripts/verify-m2-browser.mjs`：Edge 1440×900，断言 R1～R3、B4、R5 状态及题目草稿恢复，结果写入 `m2-browser.json`。
- `scripts/verify-m2-layout-matrix.mjs`：Edge 默认 100% 下 1024×768、1440×900、1920×1080 均无横向溢出，助手和关闭控件可见；结果写入 `m2-layout-matrix.json`。
- `npm run build` 通过；前端定向测试仍为先前 25 项通过。本轮未重跑 279 项后端或全套 UI，保留原报告边界。

## 尚未通过／不冒称

原生浏览器 125% 缩放、键盘 Tab 顺序、中文组合输入、PDF 内置查看器真实像素渲染和迟到事件回放仍未完成；当前文字层和状态证据不等同于这些能力通过。M2 尚未整体签收，M3 继续不开始。
