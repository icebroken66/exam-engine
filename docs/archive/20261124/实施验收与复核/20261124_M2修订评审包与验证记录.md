## 本轮修订

1. **回退契约**：由“删除新解释记录”改为停用新功能入口／写入／展示，保留解释、引用、请求、用量和版本记录；历史只读和导出继续可用，禁止回退造成用户内容丢失。
2. **真实 PDF**：样板使用 `public/review-m2/geometric.pdf` 与 `identity.pdf` 两份公开自制 PDF，实际嵌入 PDF 阅读区；正文、公式和页级来源均标注夹具性质。
3. **定位往返**：P3 有实际起点资料、证据目标资料、页级定位、返回起点和来源失效状态；不把资料页锚点冒充题目步骤锚点。
4. **题目中断恢复**：P4 有题目 A、题目 B、题目 A 草稿、资料查阅书签、返回题目 A；切换不覆盖草稿，迟到结果只显示在原主题。
5. **长答与操作边界**：P1 短答默认留在助手；P2 明确点击后展开中央阅读区；已有回答可展开／定位／重读而不生成，继续追问是新请求。样板仍是预写夹具。
6. **锚点契约**：新增 `course_id/source_sha256/preview_version/page/precision` 与 `session_id/task_id/content_version` 的类型化 Anchor；服务器负责 `valid` 和精度，客户端／模型不能自报有效。

## 启动与路径

```powershell
npm run build
npm run dev:web -- --host 127.0.0.1 --port 7176
```
