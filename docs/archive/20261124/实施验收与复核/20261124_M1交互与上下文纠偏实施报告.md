# M1 交互与上下文纠偏实施报告

日期：2026-11-24（北京时间）。范围：A03、A04、A07、A08 的可逆本地修复与确定性回归；未调用真实模型、未发送个人资料、未迁移正式库。

## 已交付

- 上下文历史：服务端为每次请求保存 include/exclude trace，区分同主题有效范围、附件移除／版本变化、最近6组上限、输入预算排除；notice 贴在对应请求，不再只在消息列表顶部显示。用户明确纠正保留原话、request_id、关系和来源标记，不能被旧摘要静默覆盖。
- 澄清：完整题干即使含“这题／本题／这段”也不再按关键词拦截；同主题唯一历史对象可继续，比较或对象冲突才等待确认。等待对象的原请求不派发；用户补充时建立新 request，记录 `clarification_of`，原冻结载荷转为 cancelled 且未派发。
- 系统状态与来源：状态卡与对应 user message 同 request-id 渲染；来源按钮显示资料名和页级精度，模型解释统一说明未经资料核验，内部 e1 等 ID 不再作为普通按钮主文案。旧失败不会常驻新问题顶部。
- 用户文字与注入：提示允许解释、转述用户主动提供的笔记／作答；越权指令仍作为数据，不执行、不扩大读取、不冒充核验课件证据。原有服务端 evidence 校验保留。
