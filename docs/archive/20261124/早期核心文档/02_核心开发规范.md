# 核心开发规范

更新：2026-11-08。合并原 06、08、11–15 的有效条款。本文是目标契约，不是功能完成声明；实际状态见 [03](03_当前状态与开发接手.md)。

## 1. 架构与职责

React / TypeScript / Vite + FastAPI / Pydantic / SQLAlchemy，当前 SQLite，后台 Worker，统一 OpenAI 兼容模型网关。先保持轻量单体，不默认引入 Redis、图数据库、微服务或多 Agent 框架。

模型理解、抽取、解释、分析错误并提出候选；代码负责来源边界、引用校验、确定性判分、状态流转、版本冲突、预算、重试和最终发布。模型声称“完成”不能直接成为数据库终态。

稳定保存 source / node / block / question / task / attempt 标识，代码按有效 ID 生成引用。摘要用于导航，原件和证据用于核对。外部资料作为数据，不能更改系统指令或工具权限。

## 2. 资料输入与覆盖

批次记录课程、来源种类、相对路径、总数与分状态数量、证据版本、开始和结束时间。单文件保存上传、解析、待确认和失败状态；部分失败不撤销成功文件。

用内容哈希去重，同名不代表同内容；同课程未变化原件应复用结果并保留导入关系。疑似混课、混学期或混角色要指出具体文件，不能由模型静默分配课程。

课程上下文同时展示已提供清单、未读取、解析失败、待确认、已有证据和真正缺失。排队资料不能说成用户未提供。首次导入默认等待本批到达可解释状态；有锚点且局部失败时，可以说明影响后使用可靠部分。

资料流程：保存原件 → 文本与页面结构提取 → 可读性检查 → 必要视觉转录与确认 → 角色 / 章节 / 考点理解 → 证据绑定 → 学习候选。

覆盖任务先列资料、章节和考点，再逐单元处理、对账。top-k、抽样、摘要和文本提取成功不能证明完整理解。每个单元记录已处理、部分处理、失败或排除及原因，缺口驱动补读和补测。

扫描、公式、表格、跨页题能回原件；低置信或缺条件不得发布为可靠题目。视觉置信度是风险信号，不是正确保证。转录编辑与完整覆盖台账仍须实现和验收。最小只读台账仅枚举现有页面 / 章节及题目、任务引用；未解析来源列占位。单元数量不是整课知识分母，有题目引用不等于整单元已理解或全部技能通过。语义处理没有可追踪记录时必须显示未知，不从范围抽样反推已完成。

网络补全先核对已有清单与具体缺口，再检索验证，保存标题、URL、获取时间、使用片段与适用性。失败不能静默用无来源内容补齐；受限平台由用户下载回传。

## 3. 真题结构化与选题

整卷按题号和语义拆分，保留题干、选项、题型、子题、分值、年份、考点、答案、解析、原卷页与证据 ID。未知年份、分值和原卷答案保持未知。缺公式、图表或初始条件进入待确认。

抽取是候选，先结构校验、题干原文对账、证据归属检查，再独立验收。选择题答案和选项一致；去重不能误合并只有分值相同的不同子题。

先匹配目标，再选择：真实原题 → 可溯源实质改编 → 课件例题 / 作业改编 → 有证据原创。重测优先不同原题，否则改变条件、推理要求或情境；只改措辞或数字不足以证明迁移。

题目明确考点 / 子技能、认知层级、诊断目的、难度依据、来源与评分要点。题干完整可答，不复制整页要求解释，不把页码或文件名作为考点。生成与验证分离，验证失败不得发布。

区分原题、改编、原创，以及原卷、AI 参考和人工修订答案。题干 / 选项与答案 / 解析分别人工确认；部分确认不冒充整题通过。编辑使旧确认失效，保留版本和理由。

## 4. 判分、纠错与无效证据

确定性判分和经过验证的等价规则优先，开放题再按评分要点、条件与证据判分。低置信（当前模型判分阈值 0.8）不能形成确定掌握结论；模型置信度不是实际正确概率，需人工对照校准。

保留答案、反馈、缺失要点、判分层级、Provider / 模型、Mock 标志、用量与引用。作答前接口隐藏参考答案和评分要点；判分后展示服务器保存作答，不以本地草稿替代。

当前与历史作答支持复核、人工纠正，保留原判分、理由与新结果。人工结果不由 AI 直接覆盖。版本过期拒绝写入；重复提交或重判不增加独立证据数。纠正后重放有效状态，旧作答不能覆盖后来的独立成功。

坏题应隔离，相关学习结论标为待复核。题目内容变化与单次重判是不同事件，不能只修答案却沿用旧条件作答作为可靠证据。完整坏题证据失效机制仍须单独开发。

## 5. 学习状态与决策

2026-11-09 教学交互细化见 [首轮开发方案](development/教学交互首轮开发方案.md)：允许围绕当前题连续交流，讨论不自动判分；实际提示 / 讲解暴露需要记录，正式作答与独立掌握继续走现有规则。该方案为待实施契约。

每次作答后：校验任务 / 版本 → 保存作答与判分 → 检查证据有效性 → 更新考点状态与证据充分度 → 选择行动并保存原因。行动包括补缺、分层追问、练习、重测、前进、请求资料与暂停。

分别记录掌握、证据数量、提示依赖、最近错误、独立成功和重测，不能只保存百分比。按概念、应用、迁移分层检查；一道难题失败不能证明全部基础不会。

| 观察 | 应考虑的行动 |
|---|---|
| 先修 / 概念缺失 | 补最小前置单元，再返回目标 |
| 方法选择错误 | 对比适用条件与方法练习 |
| 步骤错 / 执行失误 | 针对具体步骤检查，避免整章重讲 |
| 提示后或刚讲解后答对 | 撤提示、换题验证 |
| 常规题会、变式不会 | 条件对比和迁移练习 |
| 证据不足、判分不确定 | 追问、复核或暂缓确定结论 |
| 连续无进展 | 换解释、降低粒度、补先修或暂时跳过 |
| 独立重测通过 | 达到当前阶段标准，后续检查保持情况 |

补缺必须说明为什么看、如何验证、何时继续、失败怎样换策略。新资料、作答、时间变化和证据失效可以触发重排，不能固定播放预生成题单。

独立重测撤提示、换题或实质变式；即时成功不证明长期记住。完成页列出实际诊断主题、练习与重测通过次数，以及未覆盖、证据不足部分。跨轮次、延迟复测、时间规划和防循环退出按 04 分步落地，不能假定已经具备。

## 6. 历史、来源与恢复

新增资料只影响后续决策；已发布题目与作答保留使用时版本。移除资料显示影响，退出后续检索、统计、选题；历史仍可追溯。未答题引用失效来源时阻止作答并重排，最后锚点消失则要求补充。

逻辑移除和永久销毁区分；保留原件不能称已物理删除。重传相同文件尽量复用身份和有效结果。

学习写操作带任务与进度版本，模型返回后再次校验。断线或超时后先重读状态，不盲目重发；重读失败保留草稿、暂停写入。只读接口不隐式创建会话或触发付费范围分析。

进度显示真实阶段、阶段内数量与耗时，不编造百分比或 ETA。失败、取消、重启和重试最终状态一致。缓存按内容、解析器、提示词、模型和配置版本区分，不能复用过期答案。完整幂等、取消与持久恢复尚未完成。

## 7. 统计、用量与交互

频次、年份衰减、题型占比和完成计数由代码 / SQL 计算，未知年份单列。单份回忆卷不能推出跨年可靠频率或必考。考点归并保留别名与来源映射，不能改名破坏历史。

每次模型调用记录用途、Provider、模型、token、耗时、结果与错误；重试分别计量并释放失败预留。本机 token 限额不等于金额或跨电脑统一预算；费用估算不等于服务商账单。

学习页聚焦题目、作答、反馈、下一步，来源与原因可展开；阻塞、移除提示不能藏在折叠项。提供资料、校题、历史、概览入口，支持刷新、返回、窄屏及代码 / 公式 / 表格阅读。

## 8. 完成定义

交付说明变化、原因、验证和边界。按代码影响运行适当后端、前端、浏览器回归及构建；模型教学能力另有真实资料、真实调用证据。故障注入与 Mock 明确标识。

工程通过、真实模型通过、真人受益是不同证据。子项完成不代表父项完成；旧验证不冒充本轮结果。测试与正式数据隔离，保留已有修改，只停止自己启动的服务，不提交密钥或私密资料。
