# 产品原则

更新：2026-11-08。由原产品、Agent 与多资料输入基准合并，只记录有效产品决定。实现程度见 [03](03_当前状态与开发接手.md)，开发顺序见 [04](04_后续开发路线与试用计划.md)。

## 1. 定位与目标

期末急救引擎是以真实课程资料为锚点的本地复习 Agent。学生尽量提供已有课件、往年卷、作业、教师说明与笔记，系统负责接收、整理、理解和补缺，通过持续诊断、针对性复习与独立重测，帮助学生在有限时间内准备考试。

主要价值是减少手工整理、逐题录入和选择下一步的负担。核心资产是可追溯的学习证据、持续更新的学习状态，以及能据此行动的 Agent。题库、资料管理、统计与连接器服务于学习主线。

项目保留练手、作品集与真实使用经验的目标：可完成、可演示、有人实际使用；商业化与平台规模不是当前要求。产品面向多课程发展，但不能把数据库课程的验证结果推广为所有学科已可靠支持。

## 2. 产品范围

- 当前为 Web 界面的本地单用户版本。同伴分别在自己的电脑运行；多人账号、数据隔离与公开部署另行建设。
- 每门课至少有一份有效资料锚点；只有往年卷或只有课件也可开始。空白、无关、损坏或无法形成可用依据的文件不能解锁学习。
- 不要求手填考试范围或逐题录入；系统从证据提出范围，用户确认或纠正。
- 支持批量提供全部相关资料，包括清单、去重、课程归属、独立状态、失败隔离与证据版本，不能退化为逐份等待上传。
- 无资料通用诊断已经废止。通用知识与公开网络可补充已有锚点课程的解释、推理和练习，不能冒充本校范围或替代有效锚点。
- 扫描件、复杂公式、表格与图形作答按真实验证能力描述，不承诺所有课程与题型都可靠支持。
- 1037 等受限平台保留用户自行登录、下载、回传的路径；不收集密码，不绕过访问限制。

## 3. 主学习闭环

资料准备与范围确认 → 原题优先诊断 → 按作答定位缺口 → 针对性补缺 → 练习 → 不同原题或实质变式独立重测 → 更新状态并决定下一步。

每次决策使用最新有效证据、作答、提示依赖与考点状态。预先生成固定题单、顺序播放不属于逐题动态决策。

有匹配原题时优先使用原题；改编保留原题关联并实质改变任务。没有合适原题时才使用有证据原创。原卷无答案时可以求解与独立验收，但标识为 AI 参考答案。

新资料影响后续行动，不暗中重写当前题和历史。资料移除、判分纠正与题目失效必须有明确处理和留痕。

## 4. 质量底线

1. 文件名、页码、正文长句不能冒充考点。文本提取、语义理解与出题是不同阶段。
2. 题目具备完整题干、有效答案或评分依据、可定位来源；质量失败应暂停，不能以模板题凑数。
3. 原题真实性、答案来源、AI 验收与人工确认分开表达。回忆卷不是官方卷，AI 自信不是学术正确。
4. 看过讲解、提示后答对或即时模仿不等于独立掌握；本轮完成不等于整课覆盖或长期记住。
5. 资料覆盖、学习覆盖与掌握分开记录，未分析、未诊断和证据不足应可见。
6. 统计与状态由代码计算、持久化并可复算；模型提出抽取、解释、生成与行动候选。
7. 质量优先，允许必要多步验证；等待应可理解，失败应能恢复，不为赶时间跳过验收。
8. 工程测试、真实模型验收、真人学习效果分别报告，Mock 不得冒充真实结果。

## 5. 来源与冲突

当前教师、课程与学期的明确指令决定考试要求；课程资料决定校本符号、深度和上下文；往年题只说明历史情况，不承诺必考。公开资料和模型知识可补充解释，必须保留来源与适用范围。

知识正确性与课程一致性分别判断。课件、教师说明与参考答案矛盾时展示差异和引用，证据不足时请求确认或暂停相关结论，不静默覆盖。“不考”“重点”要保留章节、教师、学期和否定条件。

用户应能知道为什么安排当前题、报告坏题并复核判分。资料默认用于个人复习，不做公共传播。本地存储不意味着全程离线：相关片段会发送给配置的模型服务。

## 6. 当前取舍

本次讨论确认：现有功能足够进入 1–2 位同伴的小范围本机试用，尚不足以宣称整课覆盖可靠或教学效果已证明。

优先试用主路径、课程覆盖、跨轮次证据与延迟重测，再增强专项评分和时间规划。前端与核心易用性继续优先；模拟卷、更多渠道、复杂图谱和多人部署后置，不等待所有待办完成才试用。
