## 4. 必须保留的边界

1. 无真人学习收益证据，不能宣称优于直接模型、整课覆盖可靠或长期掌握。真人任务单列 U-01，不阻塞结构整理。
2. 范围分析最多 48 块、单块前 800 字符、合计截至 40,000 字符；诊断为最多五个不同考点。覆盖分母与语义处理未完整建立。
3. 带学保留最近 12 条成功回复，证据每块最多 4,000 字符；检索使用当前子技能和最近两条学生消息（各最多 1,000 字），12 候选 / 最多 3 补块，仍可能漏检。所有保存回复保守计帮助，不按模型 none 恢复独立性。
4. 跨轮次沿用整课资料 / 题库签名，新增无关资料也可能暂停旧记录；无版本历史不补签名，同名考点不保证同一能力。24h 建议不是遗忘模型。
5. 曾有等价 SQL 高置信误判；六个信号固定答案通过不代表专项评分全面可靠。部分得分、图形作答、坏题影响重算仍待完善。
6. 来源逻辑移除保留原件，单份永久销毁、便捷导出、完整幂等 / 取消和全链恢复仍未完成。
7. 本地单 API 进程，不具备多人数据隔离、公开部署或多实例租约保障。
